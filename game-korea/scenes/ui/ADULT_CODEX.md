# 성인 인물 도감

실행: `godot --path . res://scenes/ui/adult_codex.tscn`

다른 UI에 넣을 때: adult_codex.tscn을 CanvasLayer 아래에 인스턴스화하고 전체 화면 크기를 부여한다.

- 첨부 도감 형식: 분류별 카드, 전신과 확대 얼굴, 체력/스피드/파워.
- PNG 한 장이 아닌 Godot Control 기반 화면. 기존 PersonDrawer와 NPC 리소스를 재사용한다. 원본 일러스트와 동일한 얼굴 그림은 아니다.
- `data/codex/adult_roster.json`: 27종 카드의 능력치 제안 데이터. 해당 데이터가 실제 전투/스폰 값을 바꾸지는 않는다.
- 학생·아이·어르신·경찰 헬기는 이 도감에서 제외. 게임 스폰 변경은 별도 작업.
- 마약상은 전용 NPC 리소스가 없어 이번 화면에는 미포함.
- 창 폭에 따라 열 수 변경, 세로 스크롤 지원. 본편 메뉴 연결은 아직 없음.
- 실행/테스트 미수행.
