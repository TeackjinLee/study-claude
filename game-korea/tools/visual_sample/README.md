# 강남 교차로 비주얼 샘플

기존 게임 씬을 포함하는 실행 가능한 코드 기반 아트 프로토타입이다. 강남 교차로 `(3, 3)` 주변 3×3블록에 적용하며, 그 밖으로 이동하면 기존 도시 렌더링이 보인다. 참고 이미지 수준의 최종 픽셀 에셋을 완성한 단계는 아니다.

## 실행

프로젝트 루트에서 실행한다.

```bash
godot --path . res://tools/visual_sample.tscn
```

기존 게임과 같은 WASD 이동, Shift 달리기, F 탑승, 운전 중 Space 핸드브레이크를 사용한다. 시작 차량은 기존 택시 리소스이며, 교차로 주변에 시민과 차량을 샘플용으로 재배치한다. 전투·미션·경찰 시스템은 포함된 게임 씬의 실제 기능이다.

| 키 | 동작 |
|---|---|
| B | 시각 레이어 켜기·끄기. 같은 HUD와 게임 상태에서 도시 렌더링을 비교 |
| V | 빗줄기 켜기·끄기. 노면 반사와 차량 접지력은 그대로 유지 |
| C | 교차로 고정 카메라 / 플레이어·차량 추적 카메라 전환 |
| P | 경찰 추격 시작. 실제 수배 시스템에 사건을 전달하므로 체포·사망할 수 있음 |

앱 창에는 임시 작업명을 표시한다. 기본 프로젝트 설정·게임 씬·물리 코드는 수정하지 않는다. 저장은 `user://visual_sample_save_` 접두사를 사용한다. 샘플에서 저장한 파일이 남더라도 일반 게임 슬롯에 덮어쓰지 않는다.

## 시각 요소와 구조

- `street.gd`: 기존 건물·도로 좌표를 읽어 보도블록, 아스팔트, 옥상 설비, 창문, 한글 간판, 가로수·가로등, 빛 번짐·반사를 그린다. 실제 충돌체를 추가하지 않는다.
- `vehicle_light.gd`: 실제 차량의 위치·방향·탑승·경광등 상태를 바닥 빛에 반영한다.
- `atmosphere.gd`: 빗줄기와 화면 가장자리 음영을 그린다.
- `sample.gd`: 기존 게임을 포함하고 HUD를 배치한다. 기존 HUD의 내부 컨트롤을 사용하므로 M6에서 HUD 구조를 변경하면 이 배치도 확인해야 한다.
- `../../data/visual/gangnam_night.tres`: 색·간판·질감 시드·빗줄기 수. 시각 RNG는 게임 플레이 RNG와 분리된다.

건물 용도별로 상가의 쇼윈도·차양, 업무용 건물의 창 격자·채광창, 주거 건물의 발코니, 공장·창고의 금속 지붕·셔터를 구분한다. 주거·업무용 건물에는 용도에 맞는 세로 간판을 사용한다. 공원은 기존 렌더링을 유지한다. 한옥 등 나머지 유형의 전용 외형, 실내, 최종 인물·차량 스프라이트는 후속 작업이다. 가로등은 장식이며 새 충돌물을 만들지 않는다. 물리적 그림자·반사가 계산되는 조명 시스템이 아니라 코드로 그린 빛 번짐이다.

후속 변경(2026-10-11): 위 건물 외형 구분과 공원 복원을 추가했다. 아래 캡처·회귀 결과는 첫 샘플 기준이며 이번 변경의 테스트·새 캡처는 실행하지 않았다.

## 캡처와 확인 결과

```bash
godot --path . res://tools/visual_sample.tscn -- --capture
```

B·V·C·P 키를 입력하고 택시를 실제로 가속해 `.screenshots/m7_gangnam_*.png`에 비교·야간·빗줄기·큰 창·운전·추격 장면을 저장한 뒤 종료한다. 비교 화면에서는 게임을 잠시 멈춰 같은 순간을 사용한다. 큰 창은 1920×1080을 요청하지만 OS 화면 배율에 따라 캡처 크기가 달라질 수 있으며, 저장 시 실제 픽셀 크기를 출력한다.

2026-10-11, Godot 4.7.2 / Apple M1 Pro에서 샘플 실행·키 입력·운전·추격 캡처가 정상 종료했다. 1280×720 화면과 큰 창의 실제 캡처 2880×1620을 확인했다. 정확한 1920×1080 출력, 목표 NPC·차량 수에서의 60fps 부하 검증, 최종 아트 일치 판정은 아직 완료하지 않았다.

프로젝트 지침의 회귀 테스트 9개 중 7개 통과:

- 통과: drive, smoke, m1, police, weapon, mission, mvp.
- 실패: traffic — 10분 시뮬레이션에서 NPC 차량 충돌 1건. 첫 충돌 프레임 17442, 레미콘과 구급차.
- 실패: vehicle_damage — `먼 사람은 무사하다` 판정 실패.

두 실패 테스트는 `scenes/main.tscn`을 불러오며 이 샘플을 로드하지 않는다. 원인을 확정하거나 해당 M6 코드를 수정하지 않았으며, 실패를 해소한 것으로 표시하지 않는다. 당시 출력은 [검증 로그](../../.screenshots/m7_validation.log)에 보관했다. 기존 `tools/screenshot.tscn -- --only=m6`도 정상 종료했고 기본 강남 지도 화면을 확인했다.
