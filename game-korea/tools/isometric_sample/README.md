# 2.5D 강남 교차로

기존 XY 물리 위에 사선 투영과 건물 높이를 더한 독립 샘플. 코드 기반 구조 프로토타입이며 최종 아트가 아니다.

```bash
godot --path . res://tools/isometric_sample.tscn
```

WASD 도보(화면 방향), F 탑승, 운전 W/S 가감속·A/D 조향·Space 핸드브레이크. C 카메라, V 비, P 추격.

[Claude 인계 문서](../../docs/11_Claude_인계_2.5D.md)에 구조·확인 범위·누락된 표시·남은 작업을 정리했다. 현재 전투 조준과 일부 효과·신호등·미션 표식은 새 렌더러에 미연결이며, 다른 구역의 강·교량 표현도 미완성이다.

![미리보기](../../.screenshots/m7_isometric_gangnam.png)

## 차량 외형

`vehicle_drawer.gd`에서 차종별 유리·바퀴·범퍼·등화·적재함을 그린다. 확대 비교는 `godot --path . res://tools/isometric_sample/vehicle_gallery.tscn`으로 실행한다. 대표 8종은 같은 게임 렌더러를 사용하며 최종 픽셀 스프라이트가 아닌 코드 기반 초안이다.

## 신호·시설 안내

실제 교통 신호 상태, 은신처 저장/매물, 정비소 가격, 공중전화의 미션 상태, 현재 미션 목적지를 사선 화면에 연결했다. 화면 밖의 표시는 생략하며 안내 표식은 건물 위로 표시된다. 위의 초기 설명 중 신호등·목적지 표시 미연결 사항은 이 업데이트로 대체된다. 탄환·폭발과 전투 조준은 여전히 미완성이다.

## 차량 이미지 주행 적용

27종 PNG를 실제 차량 위치에 표시한다 (`vehicle_sprites.gd`). 현재는 단일 시점 이미지의 좌우 반전 방식으로, 정확한 회전·후면 모습과 도색 반영은 미완성이다. 조종 차량 앞의 작은 황색 화살표는 실제 진행 방향이다. 파괴 차량·미등록 차량은 도형 렌더러를 사용한다.

## 최신 상태: 차량 이미지 적용 취소

사용자 요청으로 주행 화면과 차량 도감을 도형 기반 렌더러로 복구했다. 앞·뒤 이미지와 vehicle_sprites.gd는 미사용 보관 자료다. 위의 이미지 주행 적용 설명은 현재 상태가 아닌 작업 이력이다.
