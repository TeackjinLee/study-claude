# 서울 거리 프로젝트 (임시 작업명)

기획 문서: [docs/README.md](docs/README.md) · 로드맵: [docs/08_로드맵.md](docs/08_로드맵.md) · [비주얼 제작 기준](docs/10_비주얼_제작기준.md)

## 현재 단계: M6 콘텐츠 확장 구현 (높이 레이어·플레이테스트 남음) · M7 비주얼 기준 준비

M6를 Claude Code에서 구현했다 — 구역 7개·한강·다리 3개, 장 4개와 자동 저장, 갱 3파 미션 60개, 부업 6종, 수배 ★6(헬기·군), 시간대·날씨, 무기 12종·화재, NPC 30·차량 27·건물 15종. 아래 [M6에서 추가된 것](#m6에서-추가된-것)과 [로드맵 M6](docs/08_로드맵.md#m6-콘텐츠-확장)에 결과를 적었다. 결과는 자동 테스트(m6_test 등)로 확인한 동작이고, M5 외부 플레이테스트는 아직 하지 않았다. 다리·고가 높이 레이어는 없다.

정식 게임명은 미정이다. GTA2를 제품명으로 쓰지 않고 문서 작업명을 ‘서울 거리 프로젝트’로 통일한다. 첨부 이미지 9장의 활용 범위, 시점·해상도 기본값, 강남 교차로 아트 샘플 계획은 [비주얼 제작 기준](docs/10_비주얼_제작기준.md)에 정리했다. 실행 앱과 이어 하기 메뉴의 이전 가칭은 저장 경로를 고려한 후속 변경 대상이다.

### 2.5D 화면 (본편)

본편이 사선 2.5D로 보인다. 물리·AI·충돌은 그대로 2D 평면이고, 화면에 비출 때만 눕힌다 (`scripts/world/iso_view.gd`). Codex의 [2.5D 샘플](tools/isometric_sample/README.md)과 같은 투영 각도다.

- **건물**: 동·남 두 벽과 창·1층 상가·벽 간판을 세우고, 지붕 높이에 원래 위에서 본 지붕 그림을 올린다 (`building_view.gd`). 층수·외벽 색은 `data/buildings/*.tres`의 `floors`·`wall_color`.
- **차**: 차종마다 입체 모형을 코드로 만들었다 (`vehicle_model.gd`) — [차량 이미지 기준](docs/12_차량_이미지.md)의 포스터·시트를 보고 28종의 모양·색·세부(창틀·휠·등화·거울·사다리 등)를 따랐다(이미지 파일은 쓰지 않는다). 높이는 `data/vehicles/*.tres`의 `height`. 크게 보기: `godot --path . res://tools/vehicle_gallery.tscn`.
- **사람**: 서 있는 모습으로 세워 그린다 (화면 왼쪽으로 가면 좌우 반전, 안쪽으로 가면 뒷모습). 쓰러지면 바닥에 눕는다.
- **헬기**는 공중에 뜨고 그림자가 바로 밑에 진다. 총알·불길·폭발은 가슴 높이로 띄운다.
- **그리는 순서**는 월드 x+y(깊이)로 정한다. 긴 건물은 정사각형 조각으로 나눠 옆 인도의 사람이 벽 뒤로 숨지 않게 했다.
- 주인공(또는 탄 차)이 건물 뒤에 가면 그 건물이 반투명해진다.
- 도보 `WASD`는 화면 방향(W = 화면 위 = 월드 북서쪽). 미니맵도 화면처럼 45° 돌아가고 N이 북쪽을 가리킨다.
- `F9`로 예전 위에서 보는 화면과 바꿀 수 있다.

```bash
godot --path . res://tools/screenshot.tscn -- --only=iso   # .screenshots/iso_*.png
```

남은 것: 다리·고가는 아직 납작하다(높이 레이어 없음), 공중전화·무기 상자·신호등은 바닥 표시 그대로, 최종 픽셀 아트 아님.

### 강남 교차로 비주얼 샘플

```bash
godot --path . res://tools/visual_sample.tscn
```

기존 게임에 야간 간판·도로 질감·옥상 설비·빛 반사·빗줄기와 HUD 배치를 적용한 코드 기반 첫 샘플이다. `B` 전후 비교, `V` 빗줄기, `C` 카메라, `P` 경찰 추격. [샘플 설명과 검증 결과](tools/visual_sample/README.md)에 실행 범위와 남은 작업을 기록했다. 실제 샘플 실행·캡처는 정상 종료했으며 회귀 테스트 9개 중 7개 통과, 교통·차량 피해 테스트 2개 실패를 별도로 기록했다.

### M6에서 추가된 것

- **지도** (`city_map.gd`, `city.gd`, `data/districts/*.tres`) — 강남대로(남)·한강·여의도 섬·한강변·홍대(서북)·종로(동북)·변두리(최북)·외곽 공단(강남 서쪽). 다리 셋. 강 위는 못 지나간다. 구역마다 건물 비중이 다르다 — 종로는 한옥·쪽방촌, 공단은 공장·창고, 한강변은 공원·캠핑장, 변두리는 아파트·빌라·단독주택. 건물 15종(단독주택·연립주택·원룸·공장·한옥·쪽방촌·캠핑장 새로) + 공원.
- **장(Chapter)** (`data/chapters/*.tres`) — 1장 강남(목표 ₩100만) → 2장 종로·홍대·한강변(₩300만) → 3장 여의도·변두리(₩600만) → 4장 공단(₩1,000만이면 엔딩). 잠긴 구역은 어둡게 칠해지고 담·바리케이드로 막힌다. 장이 열리면 자동 저장 칸(`user://save_auto.json`)에 저장한다. HUD 왼쪽 위에 장 목표, 다른 구역에 들어서면 구역 이름이 뜬다.
- **갱 3파 · 미션 60개** (`tools/gen_missions.py` → `data/missions/*.tres`) — 강남 조직(강남·여의도), 구도심 건달파(종로·변두리), 외곽 밀수단(홍대·공단). 갱마다 공중전화 두 묶음이 서로 다른 구역에 있고 묶음마다 쉬움 4·보통 3·어려움 3. 운반·차 탈취·레이스·수금·처치·파괴·추격·검문 돌파, 유조차(폭발 3배)·레미콘·고속버스·견인차 같은 새 차를 쓴다. 성공하면 라이벌 갱 존경도가 조금 떨어지고, 라이벌 조직원을 죽이면 오른다. 미션 표적(경호원)을 죽이면 그 갱 존경도는 3만 깎인다.
- **은신처 5곳** (`data/hideouts/*.tres`) — 강남 오피스텔·홍대 고시원(무료), 한강 캠핑장 ₩8만·변두리 단독주택 ₩5만·종로 한옥 ₩30만(처음 밟으면 살지 묻는다). 저장한 은신처에서 이어 한다. 캠핑카는 세워 두고 내리면 그 자리에서 저장.
- **수배 ★5·★6** (`police_heli.gd`, `police_dispatcher.gd`) — 특공대원을 여럿 죽이면 ★5: 경찰 헬기가 건물 위로 날아와 탐조등을 비추고(빛 안에 들면 위치가 들킨다) 기관총을 쏜다. 총으로 떨어뜨릴 수 있고, 떨어뜨리면 ★6: 군 트럭과 소총 든 군인 넷, 헬기 2대. ★4부터 가까운 다리 끝에 검문소. 쓰러진 군인은 소총을 떨어뜨린다.
- **무기 12종** (`data/weapons/*.tres`, `combat.gd`, `fires.gd`) — 새로 야구방망이(탄 없음)·소총(두 명 관통)·화염방사기·로켓런처·화염병·수류탄(멈췄다 1.6초 뒤 폭발)·차량 기관총(차 안에서 앞으로)·물대포(소방차를 몰면 공격 버튼이 물대포). 불은 사람·차를 태우고, 3초 넘게 타면 소방차가 와서 끈다. 무기 상자가 구역마다 있고 지도 끝에 비밀 상자(로켓·화염방사기)가 있다.
- **부업 6종** (`side_jobs.gd`, `data/sidejobs/*.tres`) — 택시·버스(노선 3정류장)·배달(오토바이)·응급 이송(구급차 → 병원)·소방(소방차로 불 끄기)·자경단(경찰차로 수배 차량 부수기, 수배를 풀어 준다). 부업 차에서 `B`로 시작·그만두기. 단계마다 보상과 제한 시간, 10단계를 한 교대에 끝내면 영구 보너스.
- **시간대·날씨** (`day_night.gd`) — 하루 = 실제 24분, 21시에 시작. 밤·새벽·낮·저녁 색, 3시간마다 30% 확률로 비(빗줄기, 노면이 미끄러워진다). 미니맵 위에 시계.
- **NPC 30종** — 어르신·아이(다치지 않는다)·노숙자(겁이 없다)·외국인·상인·DJ(밤 홍대)·버스커·전단 알바·교통경찰·조직 보스·여성 조직원·암살자·도둑·강도·밀수단원·소방관·군인·헬기 사수. 곁에 서 있으면 한마디 하고, 겁먹으면 "도망쳐!"를 외친다.
- **차량 27종** — 새로 스트라이커·봉고르·타이탄·유조차·청소차·레미콘·고속버스·마을버스·소방차·견인차·소방헬기(연출용, 탈 수 없다)·자전거(빼앗아도 신고 안 됨)·캠핑카·대형 화물 트럭 + 군 트럭. 구역마다 다니는 차가 다르다. 길이 80px 넘는 차는 회전할 때 맞은편 차를 쳐서 교통에 넣지 않고 주차·미션 차로 둔다.
- **넓은 도시 처리** — 교통·보행자·조직원은 카메라 둘레(약 2,500px)에만 두고 멀어지면 치운다. 경찰 길찾기는 끊긴 도로를 따라 너비 우선 탐색. 도시는 3×3 블록 청크로 나눠 그려 화면 밖은 그리지 않는다.

### M5 구현 기록

강남대로 구역에 **강남 조직**이 산다. 출발점 옆 본부(금강개발) 앞 공중전화에서 일을 받아 돈과 존경도를 번다.
미션은 10개(쉬움 4 · 보통 3 · 어려움 3)이고, 존경도가 오르면 다음 전화가 열린다. 조직원을 죽이면 존경도가 깎이고, 너무 낮으면 조직원이 보이는 대로 쏜다.
길 건너 오피스텔(은신처) 앞 초록 발판을 밟으면 세이브 슬롯(3개)을 골라 저장하고, 게임을 켜면 "새 게임 / 슬롯 1~3"에서 골라 이어 한다.

M4까지의 것도 그대로다: 무기 상자·드라이브바이·차 내구도와 연쇄 폭발·경찰 추격(★3까지)·사망과 체포.
도로에는 NPC 차 20대(세단·택시·SUV·경차·오토바이·트럭·구급차)·시내버스 2대·순찰차 3대, 인도에는 시민 24명, 강남 조직원 6명, 서쪽 골목의 폭력배 4명이 걷는다.
수배는 ★4까지 — 경찰을 여럿 죽이면 특공대가 오고, ★4는 숨어도 안 내려가서 카센터에서 도색해야 뗄 수 있다. 에셋 파일 없이 전부 코드로 그린다.

```bash
godot --path . -e     # 에디터로 열기 → F5

```

### 조작

| 상태 | 키 | 동작 |
|---|---|---|
| 공통 | `F` | 차 타기 / 내리기 (운전자가 있으면 끌어내리고 빼앗는다) |
| 공통 | `F9` | 2.5D ↔ 위에서 보는 화면 |
| 공통 | `R` | 도보로 출발점에 돌아가기 (수배 중에는 안 된다) |
| 공통 | `Ctrl` `J` 마우스 왼쪽 | 공격 (누르고 있으면 연사). 도보는 바라보는 쪽, 차 안은 좌우 드라이브바이 |
| 공통 | `Q` `E` | 이전 / 다음 무기 |
| 도보 | `WASD` | 이동 (화면 기준 — 2.5D에서 W는 화면 위 = 월드 북서쪽) |
| 도보 | `Shift` | 달리기 |
| 주행 | `W` `S` | 가속 / 브레이크·후진 |
| 주행 | `A` `D` | 조향 |
| 주행 | `Space` | 핸드브레이크 (드리프트) |
| 주행 | `1` `2` `3` | 차종 변경 (개발용): 아벨라 / 아벨라 R / 포르타 |
| 도보 | 공중전화 밟기 | 미션 받기 (본부 앞 인도, 쉬움·보통·어려움) |
| 도보 | 초록 발판 밟기 | 은신처 저장 메뉴 — 슬롯 1~3 중 골라 저장 (체력도 찬다. 수배·미션 중에는 안 된다) |
| 메뉴 | `↑` `↓` `Enter` · `1` `2` `3` · `Esc` | 슬롯 고르기 · 바로 고르기 · 닫기 (메뉴가 열린 동안 게임이 멈춘다) |
| 주행 | 카센터 정비 칸에 세우기 | 도색·수리 ₩50,000 — 수배 −2 (경찰이 보고 있으면 안 된다) |
| 주행 | `B` | 부업 시작·그만두기 (택시·버스·배달 오토바이·구급차·소방차·경찰차) |
| 도보 | 금색 "매물" 발판 밟기 | 은신처 사기 (예·아니오) |

패드: 왼쪽 스틱 이동·조향, RT/LT 가속·브레이크, A 핸드브레이크, Y 타기·내리기, LB 달리기, X 공격, 십자키 좌우 무기.

### MVP 콘텐츠 (M5 마무리)

MVP 범위([docs/00 §6](docs/00_개요.md#6-범위))의 콘텐츠 수를 채웠다: **NPC 13종 · 차량 13종 · 건물 8종 · 수배 ★4**.

- **NPC** (`data/npc/`) — 시민(남·여)·학생·직장인·경찰 + 강남 조직원·건달파 + 새로 폭력배·택시 기사·버스 기사·배달원·구급대원·특공대.
  - 차를 빼앗으면 차종에 맞는 사람이 내린다 (`VehicleType.driver_npc`): 택시 → 택시 기사, 오토바이 → 배달원, 구급차 → 구급대원, 버스 → 버스 기사.
  - **폭력배** — 구도심 건달파 소속. 서쪽 블록 넷을 돈다. 때리면 동료와 함께 주먹으로 덤비고(맨손이라 바짝 붙는다), 미션에서 건달파를 많이 죽여 건달파 존경도가 −40 밑이면 보는 대로 덤빈다. NPC 주먹은 이제 주인공도 맞힌다.

- **체포** — 벌금 ★×₩50,000, 경찰서 앞 인도에서 다시 시작한다. 수배와 출동한 경찰은 모두 사라진다.
- **★3 도로 봉쇄** — 달리는 방향의 다음 교차로를 지난 구간 한가운데에 경찰차 두 대를 가로로 세운다. 화면 밖에 세워서, 보인 뒤에도 앞 교차로에서 꺾을 여유가 있다. 한쪽 끝에 56px 틈이 있어 정확히 노리면 빠져나간다. 경찰관 한 명이 지킨다.
- **경찰차 빼앗기** — 서 있는 경찰차도 빼앗을 수 있다 (★2). 운전하던 경찰이 내려 쫓아온다.
- **경찰서·돈** — 블록 (4,2)가 경찰서(옥상 헬기장). 돈은 ₩500,000으로 시작하고 HUD 오른쪽 위에 표시한다.
- **경찰 순찰차** (`data/vehicles/police_patrol.tres`) — 최고속 800. 세단(720)보다 빠르고 스포츠(940)보다 느리다. 경광등은 추격 중에 빨강·파랑으로 번갈아 깜빡인다.

### M2에서 추가된 것

- **차선 그래프** (`lane_graph.gd`) — 교차로 49개 사이의 직선 구간 168개 + 교차로 안 이동 경로. 방향마다 차로가 둘이다: NPC는 안쪽 차로를 달리고 바깥 차로는 갓길 주차·추월용. 우측통행. 회전은 정지선부터 그리는 원호라 차종별 최소 회전 반경보다 크다.
- **신호등** — 안쪽 4지 교차로 20곳. 초록 9초·노랑 2초·전체 빨강 1초, 교차로마다 시작 시각을 엇갈렸다. 가장자리와 일부 교차로는 무신호.
- **교차로 예약** (`traffic_controller.gd`) — 정지선 앞에서 "들어온 방향→나갈 방향"을 예약한다. 12가지 이동끼리 경로가 겹치는지는 미리 계산해 둔다. 겹치는 차가 안에 있으면 기다리고, 먼저 기다린 차가 우선(좌회전 차가 굶지 않음). 나갈 차로에 자리가 없으면 들어가지 않는다(꼬리물기 금지).
- **NPC 운전자** (`traffic_ai.gd`) — 플레이어 차와 같은 물리를 쓰고 가속·브레이크·조향 입력만 만든다. 순항·회전 속도·정지선·앞차 간격 중 가장 낮은 속도를 목표로 한다. 경로 앞에 있는 차·사람·플레이어를 보고 선다.
- **비켜 가기** — 서 있는 빈 차·플레이어 차·정류장의 버스에 2초 막히면 경적("빵!")을 울리고 바깥 차로로 비켜 간다. 너무 붙어 있으면 먼저 후진해 공간을 만든다. 교차로 전에 안쪽 차로로 돌아오고, 자리가 없으면 바깥 차로에서 기다린다.
- **사고 후 복귀** — 밀려서 차선을 벗어나면 가장 가까운 차선으로 다시 합류한다.
- **시내버스** — 초록 버스 2대가 정해진 노선(4개 교차로를 시계 방향)을 돌며 정류장에서 3초씩 선다.
- **NPC 차 탈취** — 신호 대기 등으로 느린 차는 `F`로 빼앗는다. 운전자가 도망치고, 화면 밖에서 새 차가 보충된다.

### M1에서 추가된 것

- **도보 주인공** — 관성이 없다. 누르면 바로 움직이고 떼면 바로 선다. 관성이 큰 차와의 대비가 핵심. 발밑의 노란 고리로 보행자와 구별한다.
- **Director (조종권 관리자)** — 지금 사람을 조종하는지 차를 조종하는지는 `director.gd` 한 곳에서만 정한다. 사람과 차는 서로를 직접 모른다.
- **탑승·하차·탈취** — 운전석 문 90px 안에서 `F`. 문까지 0.25초 만에 가서 탄다. 운전자가 있으면 끌려 나와 도망친다("차량 탈취!"). 내릴 때 운전석 쪽이 막혀 있으면 조수석 쪽으로 내린다. 빈 차는 스스로 선다.
- **주차된 차 10대** — 그중 4대는 운전자가 타고 있다(지붕 위 머리, 켜진 헤드라이트).
- **보행자 24명** — 시민(남·여)·학생·직장인 4종(`data/npc/*.tres`). 블록 둘레 인도를 돌고 모퉁이에서 가끔 멈춘다. 배치·행동은 고정 시드로 재현된다.
- **회피·공포** — 1.2초 안에 닿을 차는 옆으로 피한다. 300px/s 넘는 차가 스치면 3초간 도망치고, 160px 안의 이웃에게 공포가 2단계까지 번진다. 차에 받히면 넘어졌다 일어나 도망친다(빠르면 죽는다 — M4).
- **차끼리 충돌** — 질량비로 충격을 나눈다. 트럭이 세단보다 덜 밀린다.
- **LOD** — 카메라에서 1500px 넘게 떨어진 보행자는 멈추고 숨긴다.

## 후속 작업: M6 진행 기록과 M7 준비

- M5 외부 플레이테스트 10명, "다시 하고 싶다" 70%↑의 결과를 기록한다. M6 진행 중이라는 사실은 이 기준 통과의 증거가 아니다.
- M6의 구역·미션·부업·수배·날씨·저장 상태를 기능별로 확인하고 로드맵에 반영한다.
- M5 당시 미구현으로 남긴 항목 중 장 시작 자동 세이브와 택시·배달 부업은 M6에서 넣었다. 구급대원 출동(사상자에 구급차가 오는 것)은 아직 없다.
- M6 남은 것: 다리·고가 높이 레이어, 비밀 패키지·광란 모드·점프대, 도둑·강도 거리 이벤트.
- M7 첫 구현은 [강남 교차로 한 장면](docs/10_비주얼_제작기준.md#5-m7-첫-산출물-강남-교차로-한-장면)으로 시작한다. 기존 코드 렌더링에서 최종 에셋으로 넘어갈 규격을 여기서 정한다.
