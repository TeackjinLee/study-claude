# 포스터 기반 차량 이미지 v1

내장 image_gen으로 사용자 제공 차량 포스터를 참조해 만든 27종 투명 배경 이미지 시트. 원본 픽셀을 그대로 추출한 파일은 아니며 생성한 재현물이다. 9열×3행, 순서는 `tools/isometric_sample/vehicle_gallery.gd`의 IDS와 같다. 모든 차량이 앞쪽 좌하단을 향하는 단일 방향이다.

차량 도감은 이 PNG를 실제 사용한다. 게임 주행 렌더러는 아직 기존 도형 방식을 사용한다. 이 그림을 평면 회전시키는 것으로 올바른 사선 차량 회전이 되지는 않는다. 방향별 시트·바닥 기준점·차종별 크기·도색/파손/경광등 처리·주행 연결이 남아 있다. 생성된 경찰차 등에 원본과 다른 표식이 있어 후속 수정이 필요하다. 따라서 최종 완료 에셋으로 취급하지 않는다.

생성 방식: 내장 image_gen, 참조 이미지 사용, transparent_background=true.

최종 프롬프트 요약: 사용자 차량 포스터의 27종을 형태·색·세부 픽셀 질감에 충실하게 재현. 도로·포스터·카드·제목·설명·브랜드 엠블럼을 제거. 투명 배경 9열×3행, 전방 좌하단 사선, 한 셀당 한 차량. 순서: 흰 세단, 검정 세단, 은색 SUV, 노랑 스포츠 세단, 빨강 경차, 파랑 고급 세단, 은색 택시, 주황 스포츠 세단, 파랑 소형 적재 트럭 / 흰 탑차, 초록 대형 탑차, 유조차, 청소차, 레미콘, 초록 버스, 파랑 고속버스, 흰 마을버스, 소방차 / 구급차, 경찰차, 특공대 차량, 견인차, 구조 헬기, 오토바이, 자전거, 캠핑카, 파랑 화물차. 단순 블록이나 로우폴리 표현 금지.

후속 업데이트: 이제 `vehicle_sprites.gd`를 통해 2.5D 주행 장면에도 연결되어 있다. 단일 시점 이미지의 수평 반전 방식이며 위의 방향별 제작·도색·파손 표현 과제는 여전히 남아 있다.

## 후면 시트 추가

`lineup_rear.png`: 내장 image_gen으로 lineup.png를 참조해 27종의 후면 사선을 새로 생성했다. 9열×3행 순서 유지, 투명 배경. 사용 프롬프트: 같은 27종·색·장비·픽셀 질감을 유지하고 차량을 월드에서 180도 회전, 앞은 우상단·뒤는 좌하단, 후면 유리·트렁크·후미등·적재함 뒷문을 표시. 단순 반전 금지, 제목·도로·로고 추가 금지.

차량 방향의 화면 투영 Y가 음수면 후면, 양수면 앞면을 선택하고 좌우 방향에 맞게 수평 반전한다. 두 원본×반전으로 네 방향을 표현하며 중간 회전각 전용 프레임은 없다. 후면은 참조에 없는 부분을 생성한 재현물이므로 세부 디자인 차이는 남는다.

최신 결정: 사용자가 이미지 차량 방식을 취소하여 주행/도감 연결을 롤백했다. 이 폴더는 미사용 보관 자료이며 현재 차량은 도형 기반으로 그린다.
