# 간판 12종

내장 image_gen으로 첨부 건물의 간판을 정면 형태로 재구성한 투명 PNG 시트. 원본 픽셀의 단순 추출은 아니다. 12개의 AtlasTexture .tres를 Sprite2D.texture에 연결해 개별 사용 가능. 본편에는 아직 연결하지 않음.

프롬프트 요약: 건물을 제거하고 오피스텔·고시원·원룸·PC방·만화·골드뷔페·외국음식·부동산·삼성빌딩·대림공업·임대·의원만 투명 4×3 시트로 재구성. 정면 직사각형, 낡은 금속 테두리, 원본 색감과 질감, 읽을 수 있는 한글.

## 본편 연결 (2026-10-12)
현재 building_view.gd에서 이 리소스들을 사용한다. 앞의 '본편 미연결'은 제작 당시 기록이다. 건물 전체는 코드 모형이며 간판만 이미지로 표시한다.

## 본편 연결 해제 (2026-10-13)
본편은 더 이상 이 이미지를 쓰지 않는다. 삼성빌딩·대림공업이 실존 상표·회사명이고, M7 전에는 코드로 그린다는 규칙 때문이다. 간판은 `BuildingView._board`(코드로 그린 금속판)가 그린다. 이 시트는 M7 참고 자료로만 남긴다.
