# 건물 조립용 PNG 16종

사용자 건물 포스터를 참고해 내장 image_gen으로 재구성했다. 원본을 그대로 잘라낸 것이 아니며 게임에는 적용하지 않았다. 투명 배경 개별 PNG는 parts/에 있다.

01~04: 벽돌 창문벽, 민벽돌벽, 콘크리트 창문벽, 유리 외벽.
05~08: 초록 평지붕, 한옥 지붕, 빨강 기와지붕, 금속 지붕.
09~12: 상점 문, 주택 문, 초록 차양, 발코니.
13~16: 노래방 간판, 서울 분식 간판, 실외기, 물탱크.

components.png: 전체 시트. manifest.json: 파일별 크기·알파 정보.

동일 규격으로 완벽히 맞물리는 타일셋은 아니다. 조립 시 크기·기준점 조정과 반대쪽 면 제작이 필요하며 일부 지붕의 경계는 가장자리 정리가 필요하다. 평지붕에는 소형 설비가 포함되어 있다.

생성 프롬프트: 한국형 건물 포스터의 거친 픽셀 질감과 사선 시점을 참고한 모듈러 건축 부품. 투명 배경 4×4, 한 칸에 독립 부품 하나. 위 순서의 벽·지붕·문·차양·발코니·간판·실외기·물탱크 제작. 좌상단 조명, 벽 가로 모서리는 우하향 26.565도. 완성 건물·도로·인물·차량·로고·설명문 제외. 간판 문구는 '노래방', '서울 분식'. 전체 시트를 PNG 영역으로 분리한 뒤 투명 여백을 제거했다.
