# 완성 건물 앞·뒤 PNG 15쌍

사용자 건물 포스터를 참고해 내장 image_gen으로 제작한 투명 배경 이미지. 부품이 아닌 지붕·벽·출입구가 결합된 완성 형태다. 원본을 그대로 추출한 것이 아니며 후면은 보이지 않는 구조를 재구성했다. 게임에는 적용하지 않았다.

- buildings/: 앞쪽 사선 PNG 15개
- rear/: 같은 번호의 뒤쪽 사선 PNG 15개 (_rear 접미사)
- buildings_atlas.png / buildings_rear_atlas.png: 전체 시트
- manifest.json: 개별 파일 크기·알파 정보

번호: 01 단독주택, 02 빌라, 03 오피스텔, 04 아파트, 05 연립주택, 06 고시원, 07 원룸, 08 상가주택, 09 상가, 10 사무실, 11 창고, 12 공장, 13 한옥, 14 쪽방촌, 15 캠핑장.

앞·뒤는 개별 생성물이라 창문·층수·옥상 설비 등이 정확하게 일치하는 3D 모델 회전 결과는 아니다. 게임용으로 연결할 때 스케일·접지점·충돌 범위와 가림 처리를 맞춰야 한다. 간판의 생성 글자도 최종 편집이 필요하다.

## 사용한 프롬프트 요약

앞면: 원본 한국형 건물 포스터의 색·재료·픽셀 질감과 사선 시점을 참고해 15종 완성 건물을 5열×3행 투명 배경에 배치. 각각 지붕부터 바닥까지 온전한 건물, 건물 간 여백, 제목·로고·도로·인물·차량 제외. 위 번호 순서 유지. 후속 편집으로 동일 칸의 중앙에 건물을 축소 배치해 분리 여백 확보.

뒷면: 앞면 시트를 참조하고 각 건물을 수직축으로 180도 돌린 반대 두 면을 재구성. 같은 지붕·색·재료·규모·순서·화풍 유지 요청. 앞면 상점 간판 대신 후면 창문·서비스 출입구·배관·실외기·비상계단 표현. 단순 좌우 반전 금지. 같은 5열×3행 투명 배경, 충분한 분리 여백.

생성 시트는 Godot Image로 영역을 무손실 분리하고 투명 여백을 잘라 개별 PNG로 저장했다.
