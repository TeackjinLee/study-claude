# 기능 건물 8종 시안

내장 image_gen으로 제작. 기존 건물 시트를 화풍 참고로 사용했다.
위: 경찰서, 병원, 강남 조직 사옥, 구도심 건달파 사무실.
아래: 외곽 밀수단 거점, 정비소, 24시 사우나, GO25 편의점.

프롬프트 요약: 한국 도시 사선 픽셀 아트 8종을 4×2 시트로 제작. 경찰서 안테나·경찰차, 병원 응급실·구급차, 검정/금색 사옥, 낡은 빨강 2층 사무실, 초록 부두 창고, 리프트 보이는 정비소, 굴뚝/온천 간판 사우나, 가상 브랜드 편의점. 기존 재료 질감과 창문 조명 유지.

배경 제거 후속 요청에도 생성 결과에 회색 배경이 남았다. 투명 게임 스프라이트가 아닌 시안이며 배경 제거/개별 분리 및 앵커 조정이 필요하다. 본편에는 미적용. 차량·소품이 건물 그림에 포함되어 있다.
