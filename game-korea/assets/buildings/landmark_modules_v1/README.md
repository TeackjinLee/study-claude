# 랜드마크 구성물 시안

내장 image_gen 사용. 프롬프트 요약: 기존 랜드마크 6종에서 차량/수면/지형을 제거하고 타워, 빈 승강장 터미널, 시장 모듈, 크레인, 방송국, 초소, 컨테이너, 창고, 차단봉 9개로 재구성. 동일 사선 시점과 질감 유지. 투명 배경 요청 및 재편집을 했으나 배경 제거는 실패했다.

현재는 배경 포함 시안이며 게임용 투명 PNG 완료본이 아니다. 개별 마스킹 및 분리 필요. 차단봉은 모터 기둥과 팔이 합쳐져 있어 실제 회전 구현에는 팔만 추가 분리가 필요하다. 시장 역시 바닥/상점 분리가 필요하다. 본편 미적용.

## 반대 방향 시안
modules_rear_concept.png: 내장 image_gen으로 앞면 시트를 참조해 9개 구성물의 반대 두 면을 재구성. 프롬프트: 같은 순서/색/지붕/질감 유지, 수직축 180도 반대 방향, 단순 반전 금지, 후면 서비스 문·배관·비상계단·설비 및 간판 뒷면 표시. 앞면과 정확히 일치하는 3D 회전 결과는 아니며 배경 포함 시안이다. 본편 미적용.
