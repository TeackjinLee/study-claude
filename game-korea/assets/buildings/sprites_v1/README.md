# 원복됨 — 미사용 참고 이미지

2026-10-12 사용자 요청으로 본편 및 도감 연결과 BuildingSpriteView를 제거했다. 아래는 원복 전 실험 기록이며 현재 동작 설명이 아니다. 이미지 파일만 보관한다.

# 첨부 이미지 직접 적용 v1

사용자가 2026-10-12 첨부한 앞면/뒷면 시트를 원본 그대로 복사했다. 각 5×3 칸의 알파 영역을 런타임에 찾아 사용한다. 재생성·배경 편집 없음.

본편 일반 건물 15종에 기본 적용. BuildingSpriteView가 화면 변환을 역으로 상쇄해 이미지를 다시 눕히지 않고 그린다. 전체 폭은 부지 투영 폭에 맞추고 앞쪽 바닥 꼭짓점에 정렬한다. 세로 띠별 깊이 정렬, 기존 주인공 가림 반투명·잠긴 지역 어둡게 처리 유지. 이미지에 포함된 마당과 중복되지 않게 해당 건물의 코드 바닥 장식은 생략한다.

- 기본: 앞면 2/3, 뒷면 1/3 (건물 번호 기준 고정).
- `--rear-buildings`: 본편 일반 건물을 모두 뒷면으로 표시.
- `--code-buildings`: 기존 코드 모형으로 실행.
- F9: 기존 탑다운 모드 유지.
- 본부·은신처·경찰서 등 특수 건물은 기존 표시 유지.
- 도감: `godot --path . res://tools/building_gallery.tscn -- --sprites` (`--rear` 추가 시 뒷면).

주의: 앞뒤는 회전 가능한 3D 모형이 아니다. 원본 해상도 제한, 이미지 간 층수 불일치, 길쭉한 부지와 그림의 바닥 비율/충돌 불일치가 남아 있다. 세로 띠 정렬은 근사이며 모든 겹침을 보장하지 않는다. 충돌은 기존 직사각형 부지 그대로다. 게임플레이와 성능 자동 테스트는 실행하지 않았다.
