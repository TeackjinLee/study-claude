# 05. 게임플레이

관련 문서: [02_캐릭터_NPC](02_캐릭터_NPC.md) · [03_차량](03_차량.md) · [04_건물_주거](04_건물_주거.md) · [06_아트_사운드_UI](06_아트_사운드_UI.md)

## 1. 코어 루프

```
 탐색 ─▶ 차량 탈취 ─▶ 미션 수락(공중전화/문자) ─▶ 미션 수행
  ▲                                              │
  │                                              ▼
 구역 해금·은신처 구매 ◀─ 무기·차량 강화 ◀─ 보상(돈·존경도)
                        (실패·체포·사망 시 → 돈 손실 후 복귀)
```

- **분 단위 루프**: 차 뺏기 → 질주 → 사고 → 경찰 추격 → 따돌리기
- **시간 단위 루프**: 갱 미션으로 존경도 쌓기 → 새 구역 해금 → 장(Chapter) 진행
- **목표 점수**: 원작처럼 장마다 목표 금액 달성 시 다음 장 해금 (1장 100만, 2장 300만, 3장 600만)

## 4. 수배 시스템 (별 6개)

| ★ | 트리거 예시 | 출동 세력 | 행동 |
|---|---|---|---|
| 0 | — | 순찰 경찰 | 범죄 목격 시 ★1 |
| 1 | 경범죄(폭행, 차량 탈취 목격) | 경찰차 1대 | 체포 시도, 발포 없음 |
| 2 | 시민 사망, 경찰 폭행 | 경찰차 2~3대 | 발포 시작 |
| 3 | 경찰 사망, 다수 살인 | 경찰차 4대 + 도로 봉쇄 | 바리케이드 |
| 4 | 지속 교전 | **특공대** 차량 | 4인 1조 돌입 |
| 5 | 특공대 사상 | **경찰 헬기** | 탐조등 추적, 기관총 |
| 6 | 극단적 혼란 | **군인** + 군 트럭 | 다리 봉쇄, 소총 |

- **감소**: 시야에서 벗어나 일정 시간 경과 시 ★ 1씩 감소. ★ 4 이상은 자연 감소 없음.
- **즉시 해제/감소**: 카센터 도색(−2), 24시 사우나에서 옷 갈아입기(−1), 경찰 뇌물 아이템(전부 해제).
- **체포**: 도보로 경찰에게 붙잡히거나 멈춘 차에서 끌려 나옴 → 가까운 경찰서 앞 재시작, 무기 압수, 벌금(★×5만).
- **사망**: 가까운 병원 앞 재시작, 무기 압수, 치료비 10만.

## 5. 갱 존경도와 미션

### 5.1 존경도
- 갱별 −100 ~ +100. 해당 갱 미션 성공 시 상승, 그 갱원 살해 시 하락.
- 라이벌 갱 미션 성공 시 반대 갱 존경도 하락.
- 존경도 높음(+40↑): 그 구역 갱원이 아군, 어려운 미션 해금.
- 존경도 낮음(−40↓): 갱원이 보이면 공격.

### 5.2 미션 수령
- **공중전화 부스**(초록 공중전화): 갱별 색상. 존경도 구간에 따라 쉬움/보통/어려움 전화기 활성화.
- **피처폰 문자**: 진행 중인 장의 스토리 미션 알림.

### 5.3 미션 유형
| 유형 | 예시 |
|---|---|
| 운반 | 제한 시간 내 포터로 "물건" 운반, 경찰 검문 회피 |
| 차량 절도 | 지정된 제니스 G8을 흠집 없이 창고로 |
| 암살 | 라이벌 보스 제거, 경호 차량 추격 |
| 파괴 | 라이벌 갱 소유 유조차 폭파 |
| 수금 | 상가 3곳 돌며 돈 받기(거부하면 가게 부수기) |
| 경주 | 홍대 → 강남 신호 무시 레이스 |
| 호위 | 조직 보스 차를 안전하게 호위 |

### 5.4 부업(Side Job)
특정 차량 탈취 시 시작: 택시 / 버스 노선 / 배달 / 구급 이송 / 소방 / 자경단(경찰차). 각 10단계, 완료 시 영구 보너스(예: 배달 완료 → 오토바이 체력 +50%).

## 6. 돈 · 점수
- **수입**: 미션 보상, 부업, 시민·차량 파괴 소액 점수(GTA2식 "점수=돈"), 거리 이벤트.
- **지출**: 은신처, 무기, 도색·수리, 벌금, 치료비.
- **배수(멀티플라이어)**: 연속 파괴 시 점수 배수 ×2~×5 (원작 감성).
- HUD 표기: `₩ 00004520` 8자리 고정 폭. M7 배치·색상 기준은 [06_아트·사운드·UI](06_아트_사운드_UI.md)와 [10_비주얼_제작기준](10_비주얼_제작기준.md)을 따른다.

## 7. 수집 요소
- **비밀 패키지** 50개(남산 전망대, 쪽방촌 미로 등) → 보상 무기 해금.
- **광란 모드(Rampage)** 아이콘 20개: 제한 시간 내 처치 목표.
- **점프대** 10개: 한강 다리 점프 등 스턴트 보너스.

## 8. 세이브
- 은신처·캠핑카에서 수동 세이브(원작은 교회 → 한국판은 은신처).
- 슬롯 3개 + 장 시작 시 자동 세이브.

## 9. 난이도와 윤리 장치
- 아이 NPC는 피격·충돌 대상 제외(등급 심의 대응).
- 옵션: 혈흔 끄기, 수배 상승 속도 조절.
