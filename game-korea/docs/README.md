# 서울 거리 프로젝트 (임시 작업명) — 기획 문서

> "서울의 거리는 너의 놀이터다!"
> 2000년대 후반~2010년대 초 가상 서울을 배경으로 한 2D 탑다운 오픈월드 액션 PC 게임 기획서.

**명칭 (2026-10-11)**: 정식 제목은 미정이며 작업명은 **‘서울 거리 프로젝트’**다. GTA2·한국판 GTA2를 제품명으로 사용하지 않는다. 기존 「그랜드 서울 오토」도 확정 제목이 아니다. 첨부 이미지 속 타사 로고·실존 상표를 새 작업물에 옮기지 않는다. → [10_비주얼_제작기준](10_비주얼_제작기준.md) · [09_법적_리스크](09_법적_리스크.md)

**진행 상태**: 사용자 공유 기준 M6는 Claude Code에서 진행 중이다. M7의 비주얼 제작 기준과 [강남 교차로 코드 샘플](../tools/visual_sample/README.md)을 추가했으며, 최종 에셋은 후속 작업이다. 이전 테스트 기록과 이번 샘플 작업의 회귀 결과(7개 통과·2개 실패)는 구분해 기록한다.

## 용어집

| 용어 | 뜻 |
|---|---|
| 수배 레벨 | 플레이어의 범죄 누적도. 별 0~6개. 높을수록 강한 진압 세력이 출동 |
| 구역(District) | 맵을 나누는 단위. 구역마다 지배 갱·분위기·스폰 테이블이 다르다 |
| 갱 존경도 | 갱별 -100~+100 수치. 높으면 그 갱 미션을 받고, 낮으면 그 구역에서 공격당한다 |
| 미션 공중전화 | 미션을 받는 지점. 원작의 공중전화를 한국식 **공중전화 부스 / 삐삐 / 피처폰 문자**로 각색 |
| 조종권(Director) | 플레이어가 지금 사람을 조종하는지 차를 조종하는지 결정하는 단일 관리자 |
| 스폰 테이블 | 구역·시간대별로 어떤 NPC·차량이 얼마나 나오는지 정의한 데이터 |
| 은신처 | 진입 가능 건물 중 세이브·무기 보관이 되는 곳 |
| 등급(1~5) | 문서 내 성능 수치는 상대 등급이다. 실제 수치는 구현 단계에서 튜닝 |
