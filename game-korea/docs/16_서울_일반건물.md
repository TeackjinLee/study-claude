## 코드 연결

- `scripts/world/street_building.gd`: 부지 비율 기반 형상 및 바닥 그림.
- `scripts/world/landmark_building.gd`: StreetBuilding으로 생성/바닥 처리 위임. 기존 collision_rects에서 지면에 닿은 Piece만 충돌한다.
- `scripts/world/building_view.gd`: street_sign / street_curtain / street_pump / street_nightlife 장식.
- `data/buildings/landmarks/`: 각 유형의 BuildingType 리소스 10개.
- `scripts/world/city.gd`: 기존 5개 랜드마크 배치를 먼저 유지한 뒤 새 10종 배치. 기능 건물 부지를 제외하고 해당 구역에서 부지를 선택한다.
- `tools/building_gallery.gd`: `--set=street` 추가.

캐노피와 주차층 슬래브는 지면보다 높은 h0를 사용해 지상 통행을 막지 않는다. 학교 운동장과 인쇄골목 중앙에도 건물 전체 사각형 충돌을 만들지 않는다.

## 확인 및 제한

Godot 에디터 import와 도감 렌더를 실행하여 오류 없이 PNG를 저장했다. 자동 테스트는 추가하거나 실행하지 않았다.

이 단계는 외형·배치 구현이다. 주유 결제/연료 보충, 모텔 숙박, 주차층 진입, 학교 활동, 지하철 이동, 소방 출동 시스템은 구현하지 않았다. 계단은 바닥 그림이며 지하 공간이 아니다. 붉은 십자가는 밝은 색상 모형이고 별도 네온 광원은 없다. 학교 담장은 기둥 표현 단계다. 새 공터의 NPC 전용 walk_loops와 주차 차량 스폰은 아직 등록하지 않았다.

추가 미술 작업: 간판 크기 및 가독성, 모텔/유흥 건물 실루엣 차별화, 주차장 경사로, 연속 담장, 점포 앞 공구/인쇄물, 네온 발광을 보강하면 좋다.

## 2차 보강 — 앞·뒤 참고 시트 반영 (2026-10-13)

기준 이미지: `output/imagegen/street_buildings/modeling_reference_v1.png`, `rear_concept_v1.png`.
이미지의 앞뒤 불일치는 코드에서 하나의 형상으로 통일한다. 이미지 텍스처를 통째로 붙이지 않고 Piece와 벽 장식으로 재구성했다.

- 교회: 더 높은 첨탑/십자가, 후면 부속실, 측면 버팀기둥과 세로 창.
- 모텔/유흥: 벽돌 재질, 높이와 폭 조정, 난간벽·물탱크·배기구·계단실, 옥상 간판. 후면 층별 발판과 계단 단을 생성하고 측면에 외부 계단과 실외기/배관 장식 추가.
- 주유소: 서비스동 옥상 설비, 가격표 형태의 안내판, 펌프 기단.
- 주차타워: 외곽 경사로를 높이가 올라가는 단으로 표현, 난간 추가. 차량의 층간 주행 물리는 구현하지 않음.
- 학교: 시계탑, 연속 담장과 정문 사이 통행 공간.
- 지하철: 기존 평판 대신 유리 채광 박공지붕, 2호선 표시 기둥. 원본의 곡면 지붕은 아직 아님.
- 소방서: 훈련탑 외부 계단, 옥상 계단실, 서비스 배관.
- 금융타워: 3단 옥탑, 세로 멀리언, 기단 테두리와 입구 화단/나무.
- 인쇄골목: 옥상 물탱크/배기구, 실외기·배관, 점포 앞 적재물.

변경 파일은 `scripts/world/street_building.gd`, `scripts/world/building_view.gd`. 기존 구역 배치 리소스를 그대로 사용하므로 게임도 보강 모형을 사용한다.

도감 렌더 결과: `.screenshots/street_buildings_v2.png`. GUI 렌더 실행은 정상 종료 및 저장되었다. 자동 테스트는 실행하지 않았다. Headless import에서 macOS 인증서 접근 및 에디터 설정 저장 권한 메시지가 있었으며 스크립트 파싱 오류는 출력되지 않았다.

남은 차이: 그림과 동일한 미술 완성도는 아니며, 네온 bloom/곡면 캐노피/실제 뒷면 카메라 전환은 미구현이다. 후면 설비는 모형에 들어가지만 현재 고정 시점에서 본체 뒤로 가려질 수 있다. 새 경사로는 시각 표현이며 다층 이동을 제공하지 않는다. 새 장식에 대한 실제 플레이 충돌/성능 검증은 별도로 필요하다.

## 3차 보강 — 가독성·곡면·야간 간판 (2026-10-13)

- `StreetDecor` 신규: 아치형 유리 캐노피(8개 곡면 구간, 7개 리브, 반사선)와 크기에 맞춘 네온 간판 렌더러.
- `BuildingView`: street_sign/nightlife/vertical_neon을 기존 LIGHT_DECOS에 연결. 야간 밝기 보정 대상이 되며 테두리 광채는 반투명 선으로 표현한다. 실시간 주변광이나 후처리 bloom은 아니다. 간판 오른쪽 끝이 속한 벽 조각이 그리도록 해 조각 사이 덮임을 줄였다.
- 모텔/유흥: 측면 세로 간판, 수평 간판 크기 및 글자 크기 조정. 커튼은 정면에만 그린다.
- 7개 유형 리소스의 visual_floor_scale 조정: 코드 모형의 고정 높이는 유지하고 창/층 띠 간격을 조절한다. 모텔 약 4층, 유흥 약 4층으로 읽히도록 보강.
- 옥상: 덕트와 점검용 발판 추가. 주유기: 호스 추가.
- 학교: 골대, 지하철: 점자블록, 소방서: 차고 번호. 지하철은 이전 박공 채광 지붕에서 곡면 유리 지붕으로 변경.
- 교회 첨탑 지붕을 벽돌 색에서 어두운 지붕 색으로 수정.

## 부지 바닥 통행 수정 — 2026-10-13

사용자 요청: 건물에 딸린 바닥으로 사람과 차량이 이동할 수 있어야 한다.

- City._build_collision: 일반/기능/랜드마크 전부 부지 전체 Rect 대신 `_pieces`의 `BuildingModel.ground_obstacles`를 사용. WORLD 레이어를 명시해 사람과 차량이 같은 장애물을 사용한다.
- Piece.blocks_ground=false는 포장·바닥판 등 통행 가능한 시각 요소. 높은 캐노피·옥상은 제외하고 사람 높이보다 낮은 물체는 실제 장애물로 남긴다. 자식 모형도 순회하여 낮은 기단 위 주유기를 빠뜨리지 않는다.
- 주유소 낮은 연석 기단은 통과 가능, 주유기는 충돌 유지.
- 단독주택·한옥 마당은 개방하고 담장만 충돌. 대문은 최대 80 월드 단위 폭으로 열고, 그림도 열린 문짝으로 맞춤.
- 최신 StreetBuilding의 기존 보행 루프·주차 차량 배치·모텔 개방 구조는 유지했다. 교통 AI의 도로 경로를 새로 변경한 작업은 아니다.

확인 범위: 코드 읽기로 플레이어/보행자/차량이 WORLD 충돌을 공유함을 확인. 이번 수정 뒤 실행·자동 테스트·실제 주행 검증은 하지 않았다. 기존 문서의 이전 테스트 통과 기록은 이번 수정에 대한 검증 결과가 아니다. 실제 통행은 문/기둥 사이 폭 및 차량 차체 크기에 영향을 받으며, 주차타워 위층 이동 기능은 포함하지 않는다.
