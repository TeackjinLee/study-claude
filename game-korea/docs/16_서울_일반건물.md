# 서울 거리 일반 건물 10종 — 2026-10-13

## 구현 범위

참고 이미지의 분위기를 코드 기반 2.5D Piece 모형으로 확장한 1차 구현이다. 이미지 스프라이트는 사용하지 않는다. 기존 LandmarkBuilding과 SpecialBuilding의 모형은 유지한다.

|---|---|---|---|
| church | 교회 | 종로 | 박공지붕, 첨탑, 붉은 십자가 |

## 코드 연결

- `scripts/world/street_building.gd`: 부지 비율 기반 형상 및 바닥 그림.
- `scripts/world/landmark_building.gd`: StreetBuilding으로 생성/바닥 처리 위임. 기존 collision_rects에서 지면에 닿은 Piece만 충돌한다.
- `scripts/world/building_view.gd`: street_sign / street_curtain / street_pump / street_nightlife 장식.
- `data/buildings/landmarks/`: 각 유형의 BuildingType 리소스 10개.
- `scripts/world/city.gd`: 기존 5개 랜드마크 배치를 먼저 유지한 뒤 새 10종 배치. 기능 건물 부지를 제외하고 해당 구역에서 부지를 선택한다.
- `tools/building_gallery.gd`: `--set=street` 추가.

캐노피와 주차층 슬래브는 지면보다 높은 h0를 사용해 지상 통행을 막지 않는다. 학교 운동장과 인쇄골목 중앙에도 건물 전체 사각형 충돌을 만들지 않는다.

## 확인 및 제한

Godot 에디터 import와 도감 렌더를 실행하여 오류 없이 PNG를 저장했다. 자동 테스트는 추가하거나 실행하지 않았다.

이 단계는 외형·배치 구현이다. 주유 결제/연료 보충, 모텔 숙박, 주차층 진입, 학교 활동, 지하철 이동, 소방 출동 시스템은 구현하지 않았다. 계단은 바닥 그림이며 지하 공간이 아니다. 붉은 십자가는 밝은 색상 모형이고 별도 네온 광원은 없다. 학교 담장은 기둥 표현 단계다. 새 공터의 NPC 전용 walk_loops와 주차 차량 스폰은 아직 등록하지 않았다.

추가 미술 작업: 간판 크기 및 가독성, 모텔/유흥 건물 실루엣 차별화, 주차장 경사로, 연속 담장, 점포 앞 공구/인쇄물, 네온 발광을 보강하면 좋다.
