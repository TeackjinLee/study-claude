# 10. 비주얼 제작 기준 · 명칭

관련 문서: [06_아트·사운드·UI](06_아트_사운드_UI.md) · [08_로드맵](08_로드맵.md) · [09_법적_리스크](09_법적_리스크.md)

작성: 2026-10-11. 사용자가 제공한 이미지 9장을 바탕으로 정리한 M7 제작 초안이다. 이미지 번호는 채팅에 첨부된 순서이며, 아래 파일명으로 식별한다. 원본은 사용자 제공 참고 자료이고 게임 에셋으로 가져온 상태는 아니다.

## 1. 확정된 방향과 제작 기본값

**후속 사용자 결정(2026-10-11):** 사선 2.5D 구현을 요청하고 작업을 승인했다. 따라서 아래 초기 탑다운 기본값에서 확장해 `tools/isometric_sample.tscn`을 만들었다. 기존 XY 시뮬레이션 위에 별도 사선 렌더러를 얹는 방식이며, 상세 현황은 [Claude 인계 문서](11_Claude_인계_2.5D.md)를 따른다.

- **사용자 요청**: 첨부 이미지처럼 서울의 거리·차량·인물이 풍부하게 보이는 화면을 목표로 한다. 게임 이름으로 GTA2를 사용하지 않는다.
- **작업명**: 문서에서는 **서울 거리 프로젝트**를 사용한다. 정식 제목과 로고는 미정이다. 기존 「그랜드 서울 오토」도 확정 제목으로 취급하지 않는다.
- **제작 기본값**: 현재의 2D 탑다운 조작과 월드 좌표를 기준으로 아트 샘플을 만든다. 건물 벽면·간판·그림자로 깊이감을 주는 방식부터 검토한다.
- **샘플에서 결정할 것**: 실제 게임의 건물 입체감, 스프라이트 크기, 렌더 해상도. 첨부 이미지의 사선 시점을 그대로 적용하는 투영 변경은 별도의 설계 결정이다.
- **배경 시대**: 현재 기획의 2000년대 후반~2010년대 초 가상 서울을 유지한다. 이미지 7의 ‘1990년대’ 표기는 시대 변경 요청으로 해석하지 않는다.

## 3. 화면을 만드는 순서

### 시점 · 해상도

- 현재 실행 설정은 `project.godot`의 1280×720, `canvas_items` 스트레치다. M7 첫 샘플도 이 설정을 기준으로 한다.
- 종전 기획의 640×360 정수배 확대는 비교 후보로 남긴다. 1280×720과 1920×1080 표시에서 한글·NPC·차량 식별력을 비교한 뒤 렌더 해상도를 확정한다.
- 32px 타일과 16×24px 인물 등 기존 규격은 초기 제안이다. 현재 코드의 월드 단위와 바로 같은 크기로 취급하지 않고, 화면에 표시되는 크기와 카메라 줌을 함께 정한다.
- 게임 중 도로 방향과 충돌 위치는 일치해야 한다. 건물 외벽이 인도나 차량을 가리면 해당 벽·지붕의 가림 처리를 먼저 해결한다.

### 색 · 조명 · 질감

| 요소 | 기본 방향 | 확인 기준 |
|---|---|---|
| 도로·지붕 | 남색·보라가 섞인 어두운 회색 `#1b1d2b`~`#3a3f55` | 차선·차량·보행자의 실루엣이 배경과 구분됨 |
| 간판 | 분홍 `#ff5ce1`, 청색 `#3ba7ff`, 빨강 `#ff3b5c` | 한 건물에 모든 강조색을 같은 밝기로 쓰지 않고 대표 간판을 정함 |
| 생활 조명 | 창문·상점·가로등의 따뜻한 황색 `#ffd23b` | 네온 사이에 생활 공간이 읽힘 |
| 젖은 노면 | 실제 광원 가까이에 제한된 반사와 빛 번짐 | 반사가 차선이나 미션 표시처럼 보이지 않음 |
| 경찰·목표 | 경찰 적·청색 경광등, 목표 황색 표시 | 밤·비·고속 주행에서도 장식 조명과 구별됨 |

질감은 아스팔트의 큰 얼룩 → 도로 표시 → 보도블록 → 작은 소품 순서로 더한다. 작은 노이즈를 화면 전체에 균일하게 뿌리지 않는다. 빗길의 시각 효과와 차량 접지력 변경은 별개 작업이며, 물리 변경은 M6 날씨 시스템과 조율한다.

### 서울 거리의 디테일

- 상가: 한글 세로 간판, 상층부 업종 간판, 작은 가게 입구와 차양.
- 옥상: 실외기·물탱크·환기구·난간을 건물 종류와 규모에 맞게 배치.
- 도로: 노란 중앙선, 횡단보도, 버스전용 표시, 맨홀, 갓길 주차.
- 인도: 가로수·전신주·공중전화·버스 정류장. 이동 통로와 상호작용 지점을 가리지 않음.
- 구역: 강남은 유리·상업 간판, 종로는 벽돌·기와·좁은 골목, 공단은 창고·화물로 구별. 세부 시설은 기존 구역 데이터와 맞춤.

### 캐릭터 · 차량 · HUD

- NPC는 실루엣과 복장색으로 직업을 구별한다. 주인공 표식과 경찰 경광등은 배경 장식보다 먼저 읽혀야 한다.
- 차량은 지붕·앞유리·앞뒤 형태로 방향을 구별한다. 회전 중 형태가 튀지 않도록 방향별 스프라이트와 연속 회전 방식을 샘플에서 비교한다.
- HUD는 원화의 큰 로고를 상시 표시하지 않는다. 미션 제목·목표, 체력·무기, 돈·수배, 미니맵의 우선순위를 먼저 잡는다.
- 돈은 원화 `₩`, 체력은 막대, 탄약은 실제 게임의 보유 탄 수 기준으로 표현한다. 재장전 기능이 확정되기 전에는 이미지의 `탄창 / 예비탄` 표기를 기능처럼 넣지 않는다.
- M7 배치 초안은 미션 상단 중앙, 체력·무기 좌상단, 돈·수배 우상단, 미니맵 좌하단, 일시 알림 우하단이다. 현재 HUD와 다른 부분은 M7 구현 계획이며, 1280×720에서 패널 간 겹침과 도로 가림을 확인한다.

## 4. 이름과 이미지 사용 규칙

- 문서 표제와 새 작업물에는 ‘서울 거리 프로젝트’를 사용한다. 정식 이름이 정해지기 전에는 별도 로고를 확정하지 않는다.
- GTA2·GTA·Grand Theft Auto·Rockstar 및 R★를 제목·제작사·로고로 사용하지 않는다. 내부 비교 설명과 기존 참고 파일명에서만 식별 목적으로 언급할 수 있다.
- 참고 이미지의 실존 차량 브랜드와 상점 표시는 기존 기획의 가칭 또는 일반 업종명으로 바꾼다. 가칭 목록이 권리 검토를 마쳤다는 뜻은 아니다.
- 참고 이미지의 한글 오류와 생성된 UI 숫자를 복사하지 않는다. 간판·대사·메뉴 텍스트는 별도로 편집한다.
- `project.godot`의 앱 이름과 이어 하기 메뉴에는 이전 가칭이 남아 있다. 문서 작업명과의 차이를 기록해 두고, 앱 이름 변경 시 기존 저장 데이터 경로와 함께 처리한다.

## 5. M7 첫 산출물: 강남 교차로 한 장면

**목적**: 전체 에셋을 제작하기 전에, 사용자가 원하는 거리 분위기와 플레이 가독성이 함께 성립하는지 확인한다.

1. 기존 강남 구역의 교차로 하나를 정하고 동일한 카메라 위치·줌의 기준 화면을 남긴다.
2. 도로·인도·상가 외형을 만든다. 가상 편의점, 노래방, 치킨집, 약국 간판과 옥상 소품을 배치한다.
3. 주인공·시민, 세단·택시·경찰차를 샘플로 제작한다. 차종 전체와 NPC 전체 제작은 이 장면의 규격을 정한 뒤 진행한다.
4. 야간 조명·빗길 반사와 HUD를 더하고 정지·도보·주행·추격 화면을 비교한다.
5. 아트 규격을 확정한 뒤 다른 구역과 콘텐츠로 넓힌다.

### 샘플 완료 기준

- [ ] 실제 게임 캡처를 이미지 4·9와 비교할 때 한글 간판·거리 밀도·야간 조명이 목표 분위기를 전달한다.
- [ ] 주인공, 경찰, 미션 목표와 주행 가능한 도로를 별도 설명 없이 구분할 수 있다.
- [ ] 1280×720 및 1920×1080 표시에서 미션·탄약·돈·미니맵을 읽을 수 있고 UI가 겹치지 않는다.
- [ ] 건물 외벽·반사·조명이 충돌 위치와 캐릭터를 가리지 않는다.
- [ ] 도보·주행·추격 중 카메라 줌과 스프라이트 회전에 눈에 띄는 흔들림이 없다.
- [ ] 에셋과 화면에 프로젝트명으로 사용된 GTA2, 타사 로고, 미교체 실존 상표가 없다.
- [ ] [07 §6](07_기술설계.md#6-성능-목표)의 목표 기기·NPC·차량 조건에서 성능을 측정하고 결과를 기록한다.

## 6. 첫 실행 샘플 (2026-10-11)

`tools/visual_sample.tscn`에 코드 기반 첫 샘플을 추가했다. 기존 강남 지도 위에 도로·보도·옥상·간판·조명·반사·빗줄기를 적용하고 실제 걷기·탑승·운전·추격과 연결했다. B 키로 기존 렌더링을 비교하고 V 키로 빗줄기, C 키로 카메라, P 키로 추격을 조작한다.

[실행 방법·검증 결과](../tools/visual_sample/README.md) · [야간 샘플 캡처](../.screenshots/m7_gangnam_rain.png)

이 샘플은 제작 방향을 살펴보는 첫 단계이며 최종 에셋은 아니다. 1280×720 및 큰 창의 캡처를 확인했지만 위 완료 기준 전체를 충족한 것으로 표시하지 않는다. 특히 최종 아트의 밀도, 차종·건물별 외형, 정확한 1080p 출력과 목표 부하 성능 확인이 남아 있다. 회귀 테스트 9개 중 2개 실패는 샘플 설명과 로그에 기록했다.

M6는 Claude Code에서 진행 중이다. M6의 맵·미션·저장 기능과 연결되는 변경은 최신 상태를 읽고 작업 범위를 맞춘다.

### 후속 구현: 건물 용도 구분

상가의 차양·쇼윈도, 업무용 건물의 창 격자·채광창, 주거용 발코니, 공장·창고의 셔터·지붕 골을 샘플에 추가했다. 주거·업무용 간판을 구분하고 공원 원본 렌더링을 유지한다. 기존 캡처는 이 후속 변경 이전 결과이며 최종 픽셀 에셋 제작과 완료 기준 판정은 남아 있다.
