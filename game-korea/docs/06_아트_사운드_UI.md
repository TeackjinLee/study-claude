# 06. 아트 · 사운드 · UI

관련 문서: [00_개요](00_개요.md) · [05_게임플레이](05_게임플레이.md) · [07_기술설계](07_기술설계.md) · [10_비주얼_제작기준](10_비주얼_제작기준.md)

2026-10-11 사용자 제공 이미지 9장을 반영했다. 이 문서는 아트·사운드·UI의 계획이며 구현 완료 목록이 아니다. 명칭, 이미지별 적용 범위와 M7 샘플의 상세 기준은 10번 문서를 따른다.

## 1. 비주얼 방향
- **키워드**: 밤, 네온, 젖은 아스팔트, 빽빽한 간판, 레트로 픽셀
- **레퍼런스**: 이미지 4의 플레이 가독성, 이미지 9의 거리 밀도·조명, 이미지 1~3의 콘텐츠 구분, 이미지 5~8의 패키지·은신처·메뉴·지도 분위기 ([파일명별 목록](10_비주얼_제작기준.md#2-이미지별-사용-목적))
- **원칙**: 탑다운에서도 "한국"이 읽혀야 한다 → 세로 간판, 한글 노면 표시("버스전용"), 국산차 실루엣, 파란 우체통, 초록 공중전화
- **시점**: 현재 2D 탑다운을 기본으로 지붕·벽면·그림자의 깊이감을 검토한다. 이미지 9의 사선 투영은 그대로 채택하지 않고 M7 첫 샘플에서 적합성을 판단한다.
- **제작 순서**: 강남 교차로 한 장면 → 규격 확정 → 다른 구역·에셋으로 확대. 타사 로고와 실존 상표는 결과물에 옮기지 않는다.

## 2. 픽셀아트 규격

아래 에셋 크기는 초기 제안이다. 실제 월드 크기·카메라 줌과 연결해 M7 샘플에서 확정하며, 현재 코드 렌더링을 이 크기로 즉시 바꾸는 지시가 아니다.

| 항목 | 규격 |
|---|---|
| 기본 타일 | 32×32 px |
| 사람 스프라이트 | 16×24 px, 8방향 × (대기 1·걷기 4·달리기 4·사격 2·쓰러짐 3) |
| 승용차 | 32×64 px, 색상 변형은 팔레트 스왑 |
| 버스·트럭 | 32×96 ~ 40×128 px |
| 건물 지붕 | 타일 조합 + 지붕 소품 스프라이트 |
| 렌더 해상도 | 현재 실행 설정 1280×720을 샘플 기준으로 사용. 기존 640×360 정수배 확대안과 비교 후 확정 |
| 조명 | 2D 라이트(가로등·헤드라이트·네온·사이렌), 노멀맵 없음 |

### 팔레트
- 밤 바닥: 남색·보라 계열 어두운 회색 (#1b1d2b ~ #3a3f55)
- 네온 강조: 빨강 #ff3b5c, 파랑 #3ba7ff, 초록 #3bff8a, 노랑 #ffd23b, 분홍 #ff5ce1
- 경찰 사이렌: 빨강/파랑 교차 0.25초

## 3. HUD (M7 배치 초안)

현재 구현은 미니맵이 우하단에 있다. 아래는 M7 화면 계획이며, 플레이 가독성을 확인한 뒤 적용한다. 이미지의 큰 로고·달러 표시·탄창 수치를 그대로 복사하지 않는다.

```
┌──────────────────────────────────────────────────────────┐
│ [체력·무기·보유 탄]     [미션·목표]        ₩ 00500000    │
│                                             ★★★★☆☆      │
│                                                          │
│                      (게임 화면)                          │
│                                                          │
│ (원형 미니맵)                      [경찰이 추격 중입니다!] │
│  N  ▲ ●                                                  │
└──────────────────────────────────────────────────────────┘
```

| 요소 | 위치 | 설명 |
|---|---|---|
| 돈 | 우상단 | `₩` + 8자리 고정 폭 숫자. 증가 애니메이션 중에도 금액을 읽을 수 있게 함 |
| 수배 별 | 돈 아래 | 6칸, 채워진 별 노랑·빈 별 어두운 초록, 상승 시 깜빡임 |
| 무기 | 좌상단 | 아이콘 + 실제 보유 탄 수. 재장전 기능이 확정되기 전에는 탄창·예비탄 구분을 넣지 않음 |
| 체력 | 좌상단 | 현재 체력 막대 유지. 차량 탑승 시 차량 내구도 막대 추가 |
| 미니맵 | 좌하단 원형 | 북쪽 고정, 빨간 점=미션/적, 파란 점=경찰 |
| 알림 | 우하단 | 반투명 검정 박스 + 흰 한글. "경찰이 추격 중입니다!", "차량 탈취!" |
| 구역 이름 | 화면 중앙 상단 | 구역 진입 시 2초 표시 ("강남대로") |
| 미션 화살표 | 플레이어 주변 | 목표 방향 노란 화살표 |

## 4. 폰트

## 6. 메뉴 · 패키지
- **메인 메뉴**: 서울 야경 위로 헬기가 탐조등을 비추는 루프 배경.
- **제목·로고**: 정식 제목 미정. 작업명은 ‘서울 거리 프로젝트’. 이미지 7의 도시·인물 구성은 참고하되 자체 제목과 제작사 표기를 사용한다.
- **패키지 아트**(컨셉 이미지 5번 방향): 선글라스 주인공 + 택시를 쫓는 경찰차 + 네온 골목 + 세로 간판. 뒷면에 스크린샷 4장 + "게임 특징" 4줄.
- **슬로건 후보**: "서울의 거리는 너의 놀이터다!", "이 도시는 당신의 것이다.", "더 거칠고, 더 자유롭게!"
- **주의**: GTA 로고 서체, Rockstar 로고, 실존 바코드·등급 마크 디자인은 모사하지 않는다(→ [09](09_법적_리스크.md)).
- **은신처·지도**: 이미지 6·8은 시각 참고다. 메뉴 항목·지역 이름·시설 표시는 실제 게임 데이터와 기능에 맞추고, 그림에 나온 미구현 기능을 자동으로 추가하지 않는다.
