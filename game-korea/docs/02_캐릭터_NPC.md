## 0. 공통 규칙

### 반응 유형
| 코드 | 반응 | 설명 |
|---|---|---|
| FLEE | 도망 | 총성·폭발·과속 차량에 놀라 반대 방향으로 뛴다. 주변에 공포 전파 |
| FIGHT | 반격 | 맞으면 주먹/무기로 반격 |
| REPORT | 신고 | 범죄 목격 시 휴대폰으로 신고 → 수배 +1 (신고 완료 전 제압하면 무효) |
| TALK | 대화 | 플레이어가 가까이 서 있으면 말풍선("안녕하세요!") |
| IGNORE | 무시 | 무관심. 직접 공격당해야 반응 |
| HOSTILE | 적대 | 플레이어를 보면 먼저 공격 (존경도·수배에 따라) |

### 성격 수치 (NPC마다 0~1 랜덤, 종별 범위 지정)
- `bravery` 용감함 → FIGHT vs FLEE 결정
- `civic` 시민의식 → REPORT 확률, 신호 준수
- `speed` 이동 속도 배율

## 5. 반응 & 상호작용 시스템

컨셉 이미지 「다양한 반응과 상호작용」을 시스템화한다.

### 5.1 자극 → 반응 표
| 자극 | 반경 | 일반 시민 | 범죄자 | 경찰 |
|---|---|---|---|---|
| 총성 | 400px | FLEE + "도망쳐!" 말풍선 | 무기 꺼냄 | 출동, 수배 +1 |
| 폭발 | 600px | FLEE + 공포 전파 | FLEE | 출동 |
| 과속 차량 근접 | 120px | 회피 점프 | 회피 | — |
| 플레이어 폭행 | 접촉 | bravery 따라 FIGHT/FLEE, REPORT | FIGHT | 체포 시도 |
| 플레이어 정지·근접 | 48px, 2초 | TALK | 시비(THUG) | 검문 대사 |
| 차량 탈취 목격 | 300px | REPORT | IGNORE | 수배 +1 |

### 5.2 공포 전파
- FLEE 상태 NPC는 반경 160px 이웃에게 공포를 넘긴다(감쇠 50%, 최대 3홉).
- 군중이 한꺼번에 흩어지는 장면이 "도시가 살아있다"는 느낌의 핵심.

### 5.3 대화 말풍선
- 종별 대사 풀 5~10줄. 예: 어르신 "젊은이, 천천히 다녀", 학생 "헐 대박", 외국인 "Excuse me?"
- 대사는 데이터 파일(CSV)로 관리해 번역 가능하게.

### 5.4 사망·부상 후처리
- 시체·혈흔은 일정 시간 후 소멸, 구급차가 오면 이송 연출.
- 경찰·특공대 사망은 수배 +2.

## 6. 데이터 정의 (요약)
NPC 종은 `NpcType` 리소스 하나로 정의한다 → [07_기술설계](07_기술설계.md#4-데이터-주도-설계)
`id, 분류, 스프라이트, hp, speed, bravery 범위, civic 범위, 무기, 반응표, 대사 풀, 스폰 가중치(구역×시간)`

### 6.1 모습 (2026-10-13 구현)
각 종의 외형(위 표의 '외형' 열)은 `NpcType`의 `outfit`·`hat`·`face`·`prop`(와 색·비율)으로 정하고 `PersonDrawer`가 코드로 그린다. 전 종 보기: `tools/person_gallery.tscn`. 아이·학생은 아직 옷 색만 다르다.
