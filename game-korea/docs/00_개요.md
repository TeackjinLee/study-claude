# 00. 개요

관련 문서: [README](README.md) · [05_게임플레이](05_게임플레이.md) · [08_로드맵](08_로드맵.md)

## 1. 한 줄 컨셉
임시 작업명은 **서울 거리 프로젝트**이며 정식 제목은 미정이다. 명칭과 첨부 이미지의 사용 기준은 [10_비주얼_제작기준](10_비주얼_제작기준.md)을 따른다.

**"다양한 사람들이 살아가는 서울의 거리, 그 속에 당신이 있다."**
네온 간판이 빛나는 밤의 서울을 위에서 내려다보며, 차를 훔치고 갱의 의뢰를 받고 경찰을 따돌리는 2D 탑다운 오픈월드 액션.

## 2. 기본 정보

| 항목 | 내용 |
|---|---|
| 장르 | 2D 탑다운 오픈월드 액션 (GTA1·2 계열) |
| 플랫폼 | PC (Windows / macOS), 1차 목표는 Steam 배포 |
| 시점 | 수직 탑다운 + 속도 비례 줌아웃 카메라 |
| 등급 | 청소년이용불가 (폭력성·범죄·언어) |
| 플레이 타임 | 메인 미션 8~12시간, 100% 완료 20시간 |
| 인원 | 싱글 (멀티는 정식 출시 이후 검토) |
| 아트 | 서울 거리의 밀도와 야간 네온을 살린 픽셀아트. 타일·스프라이트 크기와 렌더 해상도는 M7 교차로 샘플에서 확정 ([10](10_비주얼_제작기준.md)) |

## 3. 타깃
- **1차**: 20~40대, GTA1·2 / 초기 PC 게임을 기억하는 국내 게이머 — 향수 + "우리 동네" 공감
- **2차**: 한국 문화(서울 거리, K-감성)에 관심 있는 해외 인디 게이머

## 4. 핵심 재미 3가지
1. **자유로운 난장판** — 아무 차나 뺏어 타고, 아무 데나 달린다. 시민·경찰·갱이 각자 반응하며 즉흥적인 사건이 생긴다.
2. **"이거 우리 동네잖아"** — GS25 같은 편의점, PC방, 노래방, 치킨집, 마을버스, 포터 트럭, 고시원과 쪽방촌. 한국 생활상의 디테일이 웃음과 공감을 만든다.
3. **추격의 손맛** — 수배 별이 오를수록 경찰차 → 특공대 → 헬기 → 군인으로 압박이 커진다. 골목길과 한강 다리로 따돌리는 쾌감.

## 6. 범위

### MVP (수직 슬라이스, 약 6개월)
- 1개 구역(강남 번화가) 약 1.5km × 1.5km 상당
- NPC 12종, 차량 10종, 건물 8종
- 수배 1~4단계, 무기 4종, 미션 10개(갱 1파)
- 세이브/로드, 기본 HUD, 한국어만

### 정식 출시 (약 18~24개월)
- 7개 구역 전체, NPC 30종, 차량 27종, 건물 15종
- 수배 6단계, 무기 10종 이상, 갱 3파 미션 60개 이상
- 라디오 5채널, 한국어/영어

## 7. 성공 기준
- MVP 플레이테스트에서 "다시 하고 싶다" 응답 70% 이상
- 60fps 유지 (화면 내 NPC 80명 + 차량 40대 기준)
- Steam 위시리스트 1만 이상 확보 후 얼리액세스 진입
