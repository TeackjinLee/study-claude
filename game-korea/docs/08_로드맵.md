# 08. 로드맵

관련 문서: [00_개요](00_개요.md) · [07_기술설계](07_기술설계.md)

원칙: **재미가 확인된 것 위에만 다음 단계를 올린다.** 각 단계는 "완료 기준"을 헤드리스 테스트 또는 플레이 확인으로 증명해야 끝난다.
기간은 1~2인 개발 기준 추정치.

**진행 상태 (2026-10-11)**: 사용자 공유 기준으로 Claude Code에서 M6를 진행 중이다. M5 외부 플레이테스트 결과는 문서에 아직 기록되지 않았다. 아래 M0~M5 결과는 기존 기록이다. M7의 [비주얼 제작 기준](10_비주얼_제작기준.md)과 [코드 기반 교차로 샘플](../tools/visual_sample/README.md)을 추가했다. 이번 샘플 작업의 회귀 테스트는 9개 중 7개 통과, traffic·vehicle_damage 실패이며, 과거 통과 기록과 구분해 샘플 설명에 남겼다.

## 단계별 상세

### M0. 운전 감각 ✅ (2026-10-11 완료)
- **할 일**: 탑다운 차량 물리(가속·제동·횡슬립·핸드브레이크), 속도 비례 줌 카메라, 스키드 마크, 테스트 도로 1블록
- **완료 기준**: 세단·스포츠·트럭 3종이 drive_test에서 서로 다른 최고속·제동거리·선회율을 낸다. 5분 그냥 달려도 재밌다.
- **리스크**: 손맛 튜닝에 시간 소모 → 수치를 전부 VehicleType 리소스로 빼서 반복 속도를 올린다.

### M1. 도보 · 차량 탈취 · 보행자 ✅ (2026-10-11 완료)
- **할 일**: 도보 캐릭터, Director(조종권), 탑승/하차/운전자 끌어내리기, 도시 블록 생성, 보행자 배회 + FLEE
- **완료 기준**: 시민 24명이 인도를 걷고, 차에 다가가면 피한다. 탑승 전환이 0.3초 내 자연스럽다.

### M2. 교통 AI ✅ (2026-10-11 완료)
- **할 일**: LaneGraph, 신호등, 교차로 예약, 차선 추종·간격 유지·재합류, 버스 노선
- **완료 기준**: NPC 차량 20대가 10분간 교차로 충돌 0건(traffic_test). 플레이어가 막아도 정체 후 우회.

### M3. 수배 · 경찰 ✅ (2026-10-11 완료)
- **할 일**: WantedSystem(★0~3 우선), PoliceDispatcher, 경찰차 추격, 하차 도보 추격, 체포·벌금·경찰서 재시작
- **완료 기준**: ★3에서 3분 이상 도주 가능하되 쉽지 않다. 시야 이탈 시 별이 줄어든다.
- **결과**: police_test에서 자동 운전 봇이 ★3 스포츠카로 6판 도주 → 1판 3분 생존(시야 밖에서 별이 0까지 내려감), 5판은 32~62초에 체포.

### M4. 무기 · 전투 ✅ (2026-10-11 완료)
- **할 일**: 무기 4종(주먹·권총·SMG·산탄총), 드라이브바이, 무기 상자, 차량 내구도·폭발 연쇄, 플레이어 체력·병원
- **완료 기준**: weapon_test·vehicle_damage_test 통과. 폭발이 주변 차를 연쇄로 터뜨린다.
- **결과**: 두 테스트 통과. 75px 간격으로 선 세단 4대 중 하나를 터뜨리면 4대가 차례로 터지고, 500px 떨어진 차는 무사하다. ★2부터 도보 경찰이 발포한다. 차 내구도가 생긴 뒤에도 ★3 도주 균형은 M3과 같다(6판 중 1판 3분 생존, 5판 32~48초 체포).

### M5. 미션 · 갱 → MVP 🚧 (2026-10-11 시스템·콘텐츠 완료, 플레이테스트 남음)
- **할 일**: MissionSystem, 공중전화, 갱 1파(강남 조직) 미션 10개, 존경도, 은신처 세이브, HUD 1차, 강남 구역 완성
- **완료 기준**: [00_개요 §6 MVP 범위](00_개요.md#6-범위) 충족. 외부 플레이테스터 10명 테스트, "다시 하고 싶다" 70%↑.
- **결과 (시스템)**: 할 일 목록은 모두 들어갔다. mission_test 통과 — 미션 10개 완주, 시간 초과·차 파손·사망 실패, 갱 적대·아군, 저장/불러오기. 운전 미션 셋은 자동 운전 봇이 교통 속에서 실제로 몰아 제한 시간의 45% 안에 끝낸다.
- **결과 (콘텐츠)**: MVP 범위 수를 채웠다 — NPC 13종, 차량 13종, 건물 8종(+경찰서·병원·카센터), 수배 ★4(특공대, 자연 감소 없음 → 카센터 도색 −2). mvp_test 통과. ★4는 살인으로만 올라서 ★3 도주 균형은 그대로(6판 중 1판 생존, 5판 체포·사망).
- **세이브**: 은신처에서 슬롯 3개 중 골라 저장, 시작할 때 이어 하기 메뉴 (docs/05 §8의 장 시작 자동 세이브는 장 구조가 생기는 M6에서).
- **남은 것**: 외부 플레이테스터 10명 테스트.
- **원래 진입 기준**: M6 전에 재미를 검증하고 미달하면 M0~M5를 다듬는다. 현재 M6는 진행 중이나 플레이테스트 통과 기록은 없으므로 이 게이트를 완료로 표시하지 않는다. 테스트 결과와 보완 사항은 별도로 기록한다.

### M6. 콘텐츠 확장 🚧 (2026-10-11 구현 — 플레이테스트 남음)
- **할 일**: 구역 7개, 다리·고가 높이 레이어, 갱 3파 미션 60개, 부업 6종, 수배 ★4~6(특공대·헬기·군), 날씨·시간대
- **게이트 주의**: M5 외부 플레이테스트 통과 기록 없이 진행했다. 이 단계의 결과는 자동 테스트로 확인한 동작이며, 재미 검증은 아니다.
- **결과 (지도)**: 구역 7개(강남대로·종로 구도심·홍대 거리·한강변·여의도 섬·변두리 주택가·외곽 공단)를 한강과 다리 3개(하나는 여의도 섬을 지난다)로 잇는 지도. 강남 좌표는 M5 그대로다. 장마다 구역이 열린다 — 1장 강남, 2장 종로·홍대·한강변, 3장 여의도·변두리, 4장 공단. 잠긴 구역은 담과 통제 바리케이드로 막힌다. 교통·보행자·조직원은 카메라 둘레에만 두고 멀어지면 치운다. 그리기는 3×3 블록 청크 단위.
- **결과 (장·저장)**: 장 목표 ₩100만 → 300만 → 600만 → 1,000만(엔딩). 장이 열릴 때 자동 저장 칸에 저장하고, 이어 하기 메뉴에 자동 저장 줄이 생긴다. 은신처 5곳(강남 오피스텔·홍대 고시원 무료, 한강 캠핑장·변두리 단독주택·종로 한옥은 구입), 캠핑카는 세워 두고 내리면 저장. 다른 구역에 들어서면 이름이 뜬다.
- **결과 (갱·미션)**: 갱 3파(강남 조직·구도심 건달파·외곽 밀수단), 갱마다 공중전화 두 묶음(구역이 다르다) × 미션 10개 = 60개. 미션에 성공하면 라이벌 갱 존경도가 1/4만큼 떨어지고, 라이벌 조직원을 죽이면 오른다. mission_test가 1장부터 60개를 차례로 끝내 보상만으로 엔딩(₩1,065만)까지 가는지 본다. 운전 미션 23개는 봇이 제한 시간의 40~58% 안에 끝낸다.
- **결과 (수배)**: ★5 특공대원 살해 → 경찰 헬기(탐조등에 걸리면 위치가 들키고 기관총, 총으로 떨어뜨릴 수 있다), ★6 헬기 격추·군인 살해 → 군 트럭·소총 든 군인, 헬기 2대. ★4부터 가까운 다리 끝에 검문소. ★4~6은 저절로 안 내려간다. ★3 도주 균형은 그대로(6판 중 1판 3분 생존, 5판 체포·사망).
- **결과 (부업)**: 택시·버스 노선·배달·응급 이송·소방·자경단. 부업 차에서 B로 시작, 10단계를 한 교대에 끝내면 영구 보너스(택시·버스·오토바이 체력 +50%, 병원비 면제, 불 피해 절반, 벌금 절반).
- **결과 (날씨·시간)**: 하루 24분, 21시(밤)에 시작. 시간대마다 화면 색이 바뀌고, 3시간마다 30% 확률로 비 — 빗줄기와 미끄러운 노면. 사람마다 나오는 구역·시각이 있다(DJ는 밤 홍대).
- **결과 (화재)**: 화염병·화염방사기·헬기 추락으로 불이 붙고, 3초 넘게 타면 소방차가 와서 물대포로 끈다.
- **콘텐츠 체크리스트** (m6_test가 수를 센다):
  - [x] NPC 30종 ([02](02_캐릭터_NPC.md)) — 31종 (강남 조직원 포함). 아이는 다치지 않는다
  - [x] 차량 27종 ([03](03_차량.md)) — 28종 (군 트럭 포함). 80px 넘는 차는 주차·미션 전용
  - [x] 건물 15종 ([04](04_건물_주거.md)) — 공원은 부지로 따로 친다
  - [x] 무기 12종 ([05](05_게임플레이.md#3-무기)) — 주먹·방망이·권총·SMG·산탄총·소총·화염방사기·로켓·화염병·수류탄·차량 기관총·물대포
- **결과 (다리 높이, 2026-10-12)**: 2.5D에서 한강 다리 3개가 강물 위로 뜬다 — 상판(높이 46)·양끝 경사로·교각·난간·옆면, 물 위 그림자. 다리 위 차·사람·스키드 자국·불·폭발도 그 높이로 그린다. 높이는 `CityMap.ground_height`(그림 전용) 한 곳에서 정하고, 물리·충돌은 평면 그대로다 — 다리 밑은 강물이라 위아래로 겹치는 길이 없다. iso_test가 높이 곡선과 다리 위 차를 검사한다.
- **결과 (2.5D 건물 모양, 2026-10-12)**: 건물 15종을 참고 그림 '서울의 다양한 집들'에 맞춰 종류마다 다른 입체로 세운다 (`BuildingModel`: 덩어리 → `BuildingView`). 경사 지붕(박공·모임·한옥 처마), 윗층 물러남, 옥상 소품, 마당 나무·카라반·텐트·판잣집, 바닥의 담장·화단·팔레트. 충돌은 부지 사각형 그대로다. 최종 픽셀 아트(M7)는 아니다 — 코드로 그린 기준 모형. 공원 나무는 아직 바닥 그림이다.
- **결과 (고가차도, 2026-10-19)**: 강남 가로 2번 도로가 교차로 (1,2)·(2,2)를 넘는 고가차도 — 양끝 경사로·상판·옹벽·교대·난간, 넘는 교차로 밑으로 세로 도로가 지난다. 물리는 층 2단(땅 0 · 고가 위 1)으로 나눴다: 차·사람의 층은 자리가 정하고(경사로가 일정 높이를 넘으면 고가 층, 넘는 교차로 상자는 지금 층 그대로) 고가 위면 충돌 비트를 따로 쓴다. 위치로 판단하는 곳(교통 감지·치임·깔기·체포·총알)도 층이 다르면 서로 보지 않는다. 넘는 교차로는 직진만·무신호이고 경찰 길찾기는 (교차로, 지나는 축)으로 잰다. overpass_test가 지도·차선·길찾기·위아래로 지나기·벽·교통·그리는 순서를 본다. 아직 한 곳뿐이고 2층 위 사람 길(인도)은 없다. 고가 자리에 있던 테스트 지점(traffic_test 신호 대기·heli_test 착륙·m6_test 차량 기관총)은 옮겼다. 전체 테스트 통과, ★3 도주 6판 생존 1·체포 5(예전에도 나온 결과, 범위 안). 그 판에서 부서져 치워진 봉쇄 차·경찰이 봉쇄 목록에 남아 `_update_roadblocks`가 오류로 멈추던 것도 고쳤다(목록에서 거른다).
- **결과 (점프대, 2026-10-19 → 2026-10-22 뺌)**: 점프대 10개를 넣었다가 사용자 요청으로 뺐다 — 점프대·차가 뜨고 강물에 빠지는 처리·수집 저장을 모두 걷어냈다.
- **결과 (거리 이벤트·말풍선 대사, 2026-10-22)**: 랜덤 거리 이벤트 둘 — 소매치기(피해자 뒤에서 나타나 가방을 낚아채고 인도 모퉁이를 따라 달아난다), 노상강도(총으로 시민을 위협하고, 들키면 달아나며 쏜다). 주인공이 넘어뜨리면 보상(₩3만·₩6만) + 수배 −1, 죽이면 보상 절반, 멀어지면 놓친다. 미션·부업 중이거나 ★2 이상이면 벌어지지 않는다. 쫓는 범인은 머리 위 빨간 표시와 미니맵 점. 말풍선 대사는 `data/dialogue/lines.csv`(한국어·영어 칸) 하나로 옮겼고, 시민·회사원·배달원 등 대사가 없던 종에도 대사를 더했다. street_event_test가 본다.
- **남은 것**: 고가차도 더 놓기(강변북로 등), 다리 위 총알 궤적 높이, 비밀 패키지·광란 모드(docs/05 §7), 거리 이벤트 더 (편의점 강도 등), 외부 플레이테스트.
- **리스크**: 맵 제작량 — 구역은 데이터(블록 범위·건물 비중)로 정하고 배치는 자동이라 손으로 고칠 도구는 아직 없다.

- **할 일**: 최종 픽셀아트 교체, 2D 조명·네온, 라디오 5채널, 보이스, 메뉴·지도·설정, 영어 현지화
- **2.5D 본편 적용 (2026-10-11, Claude Code)**: Codex 2.5D 샘플의 사선 투영을 본편 전체에 적용했다 — 모든 구역의 건물(층수·외벽·창·상가 간판), 차(높이·옆면), 사람(서 있는 모습), 헬기 고도, 효과 높이, 깊이 정렬, 가림 반투명, 화면 기준 걷기, 미니맵 회전, F9 전환. 물리·AI는 바꾸지 않았고 기존 테스트 11개와 iso_test가 통과한다. 여전히 코드 그림이며 최종 픽셀 에셋·다리 높이·신호등 기둥 등은 남았다.
