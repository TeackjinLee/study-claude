# 03. 차량

관련 문서: [05_게임플레이](05_게임플레이.md) · [07_기술설계](07_기술설계.md) · [09_법적_리스크](09_법적_리스크.md)

컨셉 이미지 「한국판 차량 리스트」 기준 **5분류 27종**. "서울의 거리는, 이제 한국의 차들로!"

## 0. 이름 정책
- 실제 제조사·모델명(현대, 기아, 제네시스, 아반떼, 포터 등)은 **상표라 게임에 쓰지 않는다.**
- 외형은 "누가 봐도 그 차 느낌"이 나되, 엠블럼·그릴 디자인은 바꾼다.
- 가칭 브랜드: **한대(HANDAE)**, **키온(KION)**, **제니스(ZENIS)** — 확정 전 상표 검색 필수(→ [09](09_법적_리스크.md)).
- 아래 표의 "참고 원형"은 기획 내부용이며 빌드에 포함하지 않는다.

## 7. 차량 공통 시스템
- **탈취**: 빈 차는 즉시 탑승, 운전 중인 차는 운전자를 끌어내림(운전자 성격에 따라 도망/반격).
- **피해 단계**: 정상 → 연기 → 불붙음(5초 후 폭발) → 폭발. 정비소에서 수리.
- **도색**: 카센터에서 도색 시 수배 −1~−2(GTA2 Spray Shop 대응).
- **사운드**: 차종별 엔진음(경차 앵앵, 트럭 그르릉, 오토바이 부릉), 경적, 사이렌.
- **수량 목표**: 정식 27종, MVP 10종(✅ 표시).
