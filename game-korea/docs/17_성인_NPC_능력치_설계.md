# 성인 NPC 능력치 설계안

사용자 요청: 학생·아이·어르신 제외, 체력·스피드·파워로 설계.
상태: 밸런스 제안. 현재 런타임 및 .tres 수치는 변경하지 않았다.

## 기준

- 모든 등장인물은 성인. 학생, 아이, 어르신은 새 도감·스폰 대상에서 제외한다.
- 체력/스피드/파워는 각각 1~10 정수. 도감에는 동일한 순서의 10칸 막대와 수치를 표시한다.
- 체력: 버틸 수 있는 피해량. 스피드: 도보 이동·달리기. 파워: 맨손 및 근접 공격의 힘.
- 무기 화력, 방탄복, 조준 정확도, 반응 속도, 차량 속도는 별도 시스템이다. 파워로 총기 피해를 올리지 않는다.
- 성별·국적은 외형 변형이며 동일 역할의 기본 능력치는 같다. 외국인 시민도 일반 시민과 동일하다.
- 시민 능력치는 도망·생존에 사용한다. 파워가 있다고 시민에게 선제공격 AI를 부여하지 않는다.

## 런타임 연결 제안

현 코드의 NpcType에는 health, walk_speed_min/max, run_speed가 있으며 power는 없다.
설계 점수를 기존 수치와 구별해 stat_health, stat_speed, stat_power로 보관하는 방식을 권장한다.

- HP = 10 + 체력 × 2.5 (일반 시민 20, 보스 32.5). 현재 기본 시민 HP 20을 기준점으로 삼은 초안이다.
- 걷기 최소 = 35 + 스피드 × 3, 최대 = 최소 + 22.
- 달리기 = 110 + 스피드 × 12 (일반 시민 170).
- 근접 피해 배율 = 0.55 + 파워 × 0.15. 기본 무기 근접 피해에 곱한다. 파워 3이면 1배.
- NPC 개체간 외형 차이는 수치를 바꾸지 않는다. 총기/차량/폭발 피해에는 파워 배율을 적용하지 않는다.
- 보스의 전투 난도는 HP만 과도하게 늘리기보다 엄폐·호위·패턴으로 보완한다.
- 경찰/갱 전투 코드가 NpcType을 실제 참조하는지 먼저 확인한 후 공통 변환 함수를 연결한다.

## 구현 순서

1. 스폰 목록, 특수 이벤트, 갤러리, 문서의 student/child/elder 참조를 조사하여 등장 제외. 데이터 파일은 호환성 확인 없이 삭제하지 않는다.
2. 3능력치 필드·공통 변환 함수 추가. 기존 health/speed와 이중으로 관리하지 않도록 단일 원본을 정한다.
3. 시민·갱·경찰에 각자의 실제 이동/피해 경로를 연결한다. 도감만 바꾸고 전투 수치를 바꾸지 않는 오류를 방지한다.
4. 사용자가 검증을 요청하면 도주/추격/근접 피해 및 제외 NPC 미등장 확인 후 밸런스를 조절한다.

## 도감 디자인

카드 구성: 역할명 / 성인 전신 캐릭터 / 체력·스피드·파워 3줄 / 행동 설명 한 줄.
색상: 체력 빨강, 스피드 청록, 파워 주황. 색 외에도 수치와 라벨을 함께 표시.
성별 외형을 따로 보여도 같은 역할 카드의 변형으로 묶는다. 기존 GTA 로고는 사용하지 않는다.
