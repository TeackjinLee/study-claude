## 0. 진입 정책
원작 GTA2처럼 대부분 건물은 **외관만** 있다. 일부 종만 진입 가능하며, 진입 시 실내 맵으로 전환하지 않고 **지붕이 투명해지는 방식**(탑다운 유지)을 쓴다 — 로딩 없이 추격이 이어진다.

| 진입 등급 | 의미 |

| ❌ 외관 | 충돌체만 있음 |
| 🚪 1층 | 1층(상가·로비)만 진입 |
| 🏠 은신처 | 구매·해금 후 세이브·무기 보관·차고 |
| 🎯 미션 | 특정 미션 중에만 열림 |

## 3. 건물 생성 규칙
- 각 블록은 **부지 크기 + 구역 + 간판 슬롯**으로 건물 종류를 결정적(시드 고정)으로 배정한다.
- 1층 간판은 [01_세계관_서울맵 §5](01_세계관_서울맵.md#5-거리-디테일--간판-체계) 표에서 구역 가중치로 고른다.
- 야간에는 창문 일부 랜덤 점등, 간판은 네온 깜빡임.
- 지붕 위로 실외기·물탱크·옥상 텐트 등 소품을 얹어 반복감을 줄인다.
